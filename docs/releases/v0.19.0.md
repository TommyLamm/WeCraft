# v0.19.0 — B16 流動水與水桶

> 水會流了：**水源往低處流、落地後向水平擴散（最多 7 格）、失去水源後逐格退去**，
> 並加入**空桶／水桶**的裝水與倒水循環（空桶右鍵**水源**裝水、水桶右鍵方塊倒水）。
> 流動水只流入**空氣**，不沖走花草／火把、不破壞農作物；本作**不建立新水源**、
> 沒有岩漿與含水方塊。**存檔格式不升版**（本機 payload v6／雲端 format 4；
> `cloudSave` 一字未動；新 block id 41–48 append-only）。
> 執行計畫：`docs/superpowers/plans/2026-11-08-wecraft-b16-flowing-water.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B16「流動水與水桶」結案）。

## 新增

- **流動水方塊（append-only id 41–48）**：`WATER_FLOW_1`..`WATER_FLOW_7`（41–47，
  水平距離 1–7）與 `WATER_FALL`（48，下落中的水柱）。水源仍是既有的 `BLOCK.WATER`
  （id 9）。新 id 全部 `solid:false`、`transparent:true`、硬度 `Infinity`、爆炸抗性
  **100**、使用既有 `T.WATER` 貼圖、**沒有物品形式**（不進創造清單／`PLACEABLE`）。
- **流動規則（本作簡化，明示不同於原版）**：
  - 水源**永不自行消失**；流動水每 **0.25 秒**更新一次（模擬原版 5 game tick），
    每批最多處理 **256 格**（避免單幀風暴；`dt` 過大不補償多批）。
  - 水平流動最多 **7 格**；下方是空氣時優先往下形成 `WATER_FALL` 水柱；水柱**不向
    側面擴散**，落地（下方不是空氣）後才變成 `FLOW_1` 並向水平擴散。
  - 流動水只能流入**空氣**；不會沖走花草、火把、農作物，也不會與水以外的方塊互動
    （沒有岩漿、沒有黑曜石／鵝卵石生成）。
  - **不建立新水源**：兩個相鄰水源不會在中間生成新水源，沒有原版的無限水。
  - 水源被移除、支撐消失、或路徑被方塊擋住時，流動水會在後續 tick 逐格退去；
    退去是**單調**的（方向性供給：供給鏈斷掉的格子直接變空氣，不會先「變弱」再
    消失，也不出現水位迴漲的波；垂死的鄰居不算供給——T2-1／T2-2 裁決）；但多水源
    同時失效的複雜地形可能出現 **1–2 tick 的暫態漣漪**，仍會在有限 tick 內收斂
    （明示的實作近似）。
  - **不寫入未載入的區塊**：流動模擬只在已載入區塊內讀寫；區塊載入後會從
    `modified` overlay 重新排程，跨區塊邊界的水流會在載入後恢復。
- **水桶**：新增 **桶子（`bucket`）** 與 **水桶（`water_bucket`）** 兩個物品，皆
  堆疊 1；桶子配方＝**3 個鐵錠的 V 形**（上排左右各一、中間下方一）。
  - 手持空桶右鍵**水源**（`BLOCK.WATER`，不含流動水／水柱）→ 水源變空氣、空桶變
    水桶；只在水源是射線最近命中時生效（不能穿過較近的實心方塊裝水）。
  - 手持水桶右鍵方塊 → 在可放置的目標格放一個水源，水桶變回空桶；放置目標沿用
    既有 `resolvePlacementTarget` ＋ `canPlaceBlockAt` 規則（可取代空氣／水／花草；
    不與玩家 AABB 重疊）。生存模式一對一替換、創造模式不消耗。
  - 水桶**不可合成**（只能由裝水取得）；不支援裝魚、牛奶、岩漿。
- **渲染**：所有水源／流動水／水柱都走既有半透明 water pass，**以滿格方塊繪製**
  （不依水位降低表面高度——明示簡化）；同一流體的不同 id 之間不畫內部面。
- **效能**：流動水寫入走新的 `World.setFluid`（只記 `modified`、標記網格，
  **不觸發光照重算**——水與空氣都是透明方塊，光照不變）；外部方塊編輯仍走
  `setBlock` 並正常重算光照。水的寫入不建立未載入的區塊。
- **流動水也參與既有水判定**：射線（`includeWater`）、玩家在水中的物理／水下霧、
  釣魚水面、耕地濕潤、放置取代都接受水源／流動水／水柱；不死系站在流動水裡同樣
  不會被日光曬傷，雨天曝露與雨絲隱藏也把流動水視為水。

## 修正

- **無對玩家可見的修正**。本批是純新增功能；實作期間的內部調整：
  - `WaterSim` 的方向性供給與**單調退去**（commit `464c180`）：移除水源後不得出現
    「水位先迴漲再消失」的波——流動水只接受更近水源的候選、候選變大即退成空氣，
    且**垂死的水平鄰居不算供給**（往下探一層的穩定性檢查）。以 `world/water.test.ts`
    的退去／阻擋／7 格上限測試釘住。
  - **流動水也算水**（commit `5f5ea85`，測試 `4b49fac`）：日曬（不死系不燒傷）、
    雨天曝露（雨絲室內隱藏）與水下霧的判定從 `=== BLOCK.WATER` 改走 `isWaterBlock`；
    否則玩家站在流動水裡會被誤判為露天／陸地。
  - 音效表補上 8 個新 block id（全部 `'water'`）、`ui/menus.ts` 的暫停操作提示補上
    水桶說明；`audio.play` 只新增 `playBucketSound` 一個呼叫點（總數 7 → 8）。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **新方塊 id 是 append-only（41–48）**；流動水會進既有 `modified` overlay
   （來源格與流動格都照既有機制保存），載入時重排程流動水。失去水源的流動水會在
   載入後退去。
3. **回退到 0.18.0 時**：流動水／水柱 id 未知 → 顯示為**空氣**（水源不受影響）；
   存檔本身照常可讀，**沒有新增回退阻擋**；回到 0.19.0 後那些格子仍會依當時的
   水源狀態重新流動（除非在 0.18.0 改動過那一格）。
4. **新物品 id（桶子／水桶）會被舊版清洗** → 回退到 0.18.0 時背包／箱子裡的桶子與
   水桶消失，回到 0.19.0 後不會自動回來。
5. 沒有新增存檔欄位；0.18.0（含）以前的存檔在新版可正常讀取。

## 已知問題／簡化

- **不渲染水位高度**：所有水源／流動水／水柱都以**滿格方塊**繪製（原版水面會依
  水位下降）；同一流體的不同 id 之間不畫內部面。
- **不建立新水源**：兩個相鄰水源不會在中間生成新水源，沒有原版的無限水。
- **不沖走植被／火把、不破壞農作物**：流動水只流入空氣；花草／火把／小麥都不受影響。
- **沒有岩漿與流體互動、沒有含水方塊（waterlogging）**：不生成黑曜石／鵝卵石，
  水也不會流進樓梯／柵欄等方塊。
- **流動與下落同為每 0.25 秒一格**：水平流動與水柱下落共用同一個 tick（原版下落
  更快、水面會平滑衰減）；每批最多 256 格，`dt` 過大不補償多批。
- **只從水源裝水**：流動水與水柱不能裝；空桶只能裝射線最近命中的水源。
- **水桶不可裝其他液體**：不支援魚、牛奶、岩漿；水桶不可合成。
- **流動水只在已載入區塊內模擬**：跨區塊邊界的水流會在區塊載入後從 `modified`
  overlay 重排程恢復；載入後失去水源的流動水會退去。
- **退去可能出現短暫漣漪**：單一供給鏈斷掉時退去是單調的；多水源同時失效的複雜
  地形可能出現 **1–2 tick 的暫態漣漪**，仍會在有限 tick 內收斂（明示的實作近似）。
- **沒有流動水音效**：裝水／倒水沿用既有 water 材質音。
