> B10 弓與箭、床與重生點：能蓄力射箭的弓、可合成／可撿的箭、能跳過夜晚並設定
> 重生點的床——把 B4 就有的骷髏箭實體擴充成玩家武器，把 B9 的線接進羊毛→床的
> 循環。**存檔格式不升版**（本機 v6／雲端 format 4 不變，`spawnPoint` 是附加欄位）。
> 執行計畫：`docs/superpowers/plans/2026-11-01-wecraft-b10-bow-and-bed.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B10）。

## 新增

- **弓**（3 線＋3 木棍合成）：耐久 **384**；**按住右鍵蓄力、放開發射**（滿蓄 1 秒）；
  傷害依原版蓄力分桶 **1／5／6／6–11**（滿蓄暴擊 6–11）；每次射擊扣 1 耐久；
  **創造模式不耗箭、不扣耐久**；沒有箭時提示「沒有箭了」且不發射。
  第一人稱拉弓姿態（icon mesh 後拉＋上仰，隨蓄力增強）；換格／弓離手即取消蓄力。
- **玩家箭**：沿用 B4 的箭實體（掃掠子步進、重力 9.8、30 秒消失），速度
  **40 格/秒 × 蓄力**、每軸 ±0.3446 格/秒的誤差（原版 inaccuracy 1 的近似）。
  可命中**殭屍／骷髏／苦力怕／蜘蛛／被動生物**（AABB 掃掠、同幀取最近目標、
  同一幀第二支箭不重複結算）；命中**生物**即消耗並套用蓄力傷害（蜘蛛眼／進度/
  掉落表照既有規則：箭＝玩家擊殺）；命中**方塊**落地成**一支可撿的箭**
  （生存模式）；**玩家箭不會打到發射者**；骷髏箭行為不變（只傷玩家、不可撿）。
- **箭的來源**：**燧石＋木棍＋羽毛 → 4 支**；**礫石 10% 掉燧石**（其餘掉礫石，
  **僅手動挖掘**；爆炸仍掉礫石本身）；骷髏掉 0–2 支（既有）。
- **骷髏 8.5% 掉弓**：原版裝備掉落——**只在玩家（或原版的馴狼）擊殺時**掉
  （沿用 B9 蜘蛛眼的 `killedByPlayer` 閘門；爆炸死因不掉）；本作掉**滿耐久**的弓。
- **四個新配方**：弓（3 線＋3 木棍）、箭（燧石＋木棍＋羽毛 → 4）、
  **4 條線 → 1 羊毛**（shapeless；把 B9 的線接進循環）、
  **床**（上排 3 羊毛＋下排 3 木板，板材可混用）。物品表 77 → **79**
  （0.13.0 先加 `bed`，本批再加 `flint`／`bow`）。
- **床**（3 羊毛＋3 木板）：硬度／爆炸抗性 **0.2**、掉自身、**堆疊 1**（原版床
  不可堆疊）、**單一方塊**（無方向的簡化）、木頭音效。
- **床的使用**：**右鍵 3 格內**使用；可睡＝**時間的內部天空光 ≤ 11**
  （本作曲線的實際窗口約 t 0.488–1.0，跨午夜）；**8 格水平／5 格垂直**內有
  敵對生物不可睡；**睡 5.05 秒（101 tick）跳過夜晚**——時間跳到日出 t = 0，
  附全螢幕黑幕（`ui/sleep.ts`，冪等 show/hide；醒來直接切回）。
  **右鍵床一律設定重生點**（白天或有怪物時只提示、不睡——與原版一致）。
- **重生點**：`spawnPoint` 附加欄位進**本機 payload v6** 與**雲端 format 4**
  （**兩個格式號都不升**；舊版讀到新存檔會忽略這個鍵）。死亡後床還在原格 →
  重生在**床頂**；床被**拆掉或炸掉** → 重生點自動失效、回世界出生點；
  新局／回標題維持世界出生點（避免環繞相機跑到未生成區域）。
- **弓與箭的音效**（加分項，已實作）：發射「咻」（0.14 秒帶通噪音）＋
  命中「咚」（低通噪音＋ 220 Hz 短正弦）；距離衰減與其他音效一致。

## 修正

- **本批沒有既有行為的修正**（沒有玩家可見的舊 bug 修復）。既有測試的改動
  都是「改得有理」：物品／配方／tile 計數成長、骷髏掉落期望加入弓、
  `damageHeldTool(1)` 呼叫點 5 → 6（新增射箭扣損）、`requiredTool` 窮舉表補床、
  音訊材質表補床（木頭）——沒有為了綠燈而放寬任何守門。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**：`spawnPoint` 是**附加 optional 欄位**——
   0.12.0 讀到 0.13.0 的存檔會忽略它；0.13.0 讀到舊存檔 → `spawnPoint: null`
   （回世界出生點）。**回退到 0.12.0 只會失去床的重生點**，存檔照常可讀。
2. **雲端格式不變（format 4）**：`cloudSave` 一字未動（`readableFormats [1,2,3,4]`、
   `writeFormat 4`）；`spawnPoint` 同樣是附加欄位，舊版忽略、髒值整包拒收。
3. **舊存檔照常載入**：0.12.0（含）以前的存檔在新版可正常讀取（床的重生點為空）；
   **沒有新增回退限制**；0.10.0 以前既有的回退限制維持不變
   （見 `docs/releases/v0.11.0.md`）。
4. **床的放置／破壞照既有方塊規則**：`modified` overlay 記數字 id 34 →
   Save & Quit → Continue 後床仍在；拆床／炸床會清掉重生點。

## 已知問題／簡化

- **床是單一方塊**：無方向、無床頭／床尾兩格、無佔用狀態、無躺床動畫；
  醒來固定在床頂一格（原版會搜尋周圍空位；本作由碰撞把玩家推開——重生點可能
  被方塊佔住，沒有「床被阻擋」判定）。
- **睡眠時間窗用時間的內部天空光**（不讀床格的光）：本作曲線窗口約
  t 0.488–1.0（跨午夜），比原版 12523–23477 ticks（≈ 0.522–0.978）**略寬**；
  無雷雨（原版雨天白天也能睡）、無 phantom／失眠機制。
- **白天使用床只設定重生點、不睡覺**（原版白天在暗處也不能睡——時間窗口是主判準）；
  有怪物時**仍設定重生點**、只是不能睡（與原版一致；時間判定在怪物判定之前）。
- **箭命中生物即消耗**（原版箭會插在生物身上，通常也拿不回來）；只有命中方塊
  才掉可撿的箭；骷髏箭永遠不可撿、不掉落物（既有行為）。
- **箭速 40 格/秒 × 蓄力**（原版滿蓄 60）；重力 9.8（原版 20）；**無暴擊粒子**、
  無箭的火焰／藥水效果、無附魔（Power／Infinity／Flame）；**拉弓不減慢移動速度**
  （原版會）。
- **骷髏掉弓是滿耐久**（不模擬裝備耐久）；骷髏不顯示弓的模型、也不會射「有弓的
  骷髏」以外的變化。
- **礫石 10% 掉燧石只在手動挖掘**；爆炸炸掉的礫石掉礫石本身。
- **睡眠黑幕是純黑 CSS 覆蓋層**：元素掛上即全黑（掛載當幀不跑 0→1 的過渡）；
  醒來直接切回、無淡出。睡眠中不解除 pointer lock（世界凍結、輸入無效）。
- **弓與箭音效是程序合成的近似音**（原版 `entity.arrow.shoot`／命中取樣）。
- B2–B9 中尚未完成的功能維持既有說明（見 README〈與原版的差異〉）。
