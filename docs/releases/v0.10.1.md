## 存檔格式與相容性提示

1. **存檔格式不變**：本機 payload 維持 **v5**（堆疊帶 `dur`）、雲端維持 **format 3**
   （`readableFormats:[1,2,3]`、`writeFormat:3`）；`game.json` 的 `cloudSave` 一字未動。
   **0.10.0 ↔ 0.10.1 的存檔雙向相容**（本機與雲端皆是），沒有新的回退限制。
2. **世界生成版本不變**：`WORLDGEN_VERSION` 維持 2 → 0.10.0 的存檔載入時**不會**跳
   「地形已改變」提示（本批不動地形生成）。
3. **0.9.0 以前的回退限制沿用**：`docs/releases/v0.10.0.md` 的〈存檔格式與相容性提示〉
   （雲端 format 3／本機 v5 對 0.9.0 的不可回退）不因本版改變。

## 修正

### 雲端存檔與標題流程

- **回應遺失的同 ID 重送**：送出後沒有回應的檢查點，重試時沿用**凍結的 requestId**
  與完全相同的快照（平台契約的冪等重送）；換新 ID 會變成第二次寫入、把 revision
  推歪並撞出 409。現在 revision 只在收到確認後前進。
- **只有 `saved:true` 才算保存**：平台回應缺 `saved` 旗標時視為「未確認」——保留
  快照與 revision、維持可重試，UI 顯示「尚未同步」，不再把未確認的回應當成成功。
- **409 衝突改為玩家三選一**：保留本機／採用雲端／合併。對話框開啟期間**停止所有
  寫入**（暫停選單有「有新進度」列與重試），不再默默覆寫任何一邊。
- **標題先掛、雲端背景載入**：標題畫面立即出現，雲端檢查在背景跑；「繼續遊戲」
  在答案確定前是 disabled，慢網路不再卡住開機。
- **本機存檔失敗可見**：「儲存並離開」失敗會留在遊戲內（不再假裝離開成功）；
  autosave 失敗有提示與重試。
- **session 邊界清理 UI 狀態**：返回標題／新局／讀檔時清掉游標堆疊與合成格舞台
  材料（滿背包也不再複製），並把疾跑／FOV 等跨場次殘留歸零。
- **標題三態每次重新推導**：場中存檔（autosave／儲存並離開）之後回到標題，
  「繼續遊戲」立即出現且可按、新遊戲恢復覆蓋確認——之前快取在開機的 `'no'` 會讓
  下一場 autosave 靜默蓋掉剛存的進度。
- **標題上的「採用雲端」**：在標題畫面解決 409 並採用雲端時，會正確標記為
  「開機已套用的雲端進度」→「繼續遊戲」走雲端分支，不再被舊的本機快照蓋回去。

### 遊戲性

- **被動生物只在白天生成**：生成排程加上白天閘門（`isDaylight`），夜間不再生成。
- **被動群組恆為 2–4 隻**：放不下整群（全場上限 12 或地形只剩 1 個落點）就整輪
  放棄、下一輪再試，不再出現 1 隻的「群」。
- **一次按壓只吃一份**：按住右鍵完成一次進食後，鎖存到放開為止（不會每 1.6 秒
  重複吃）。
- **仙人掌是 solid 遮擋**：射線不會穿過仙人掌挖／放背後的方塊。
- **無支撐的 cross 方塊移除**：花草失去支撐時掉落，不再懸空。
- **未點光區塊 ≠ 黑暗**：`chunk.light` 尚未算好時視為「未知」，白天不再誤生敵對
  生物（夜晚照常）。
- **疾跑取消原因進 HUD**：停止前進／潛行／飢餓／水中／飛行中／撞牆／攻擊命中
  各有提示文案（畫面下緣、熱鍵列與數值列上方；2 秒）。

### 效能與版面

- **編輯卡頓分幀**：放置／破壞後的單塊重算與網格化改為分幀處理（就緒優先），
  3×3 群組重照 5.9 ms/chunk（門檻 8）。效能門檻改成獨立指令
  `npm run test:perf`（絕對牆鐘值，平行跑會膨脹約 2 倍）。
- **worker 逾時與分幀退路**：地形 worker 逾時不再卡住佇列，改走主執行緒分幀排空。
- **工作台 3×3 來源列換行**：36 格來源列固定 4 列 × 9 格、44 px，全部留在畫面內
  可點（原本一長列被擠出面板）。
- **生存 HUD 上移**：血量／飢餓列不再與熱鍵列重疊。
- **「回到標題」二次確認**：不存檔離開前先問（取消／Esc 回到暫停選單）；
  死亡畫面的離開維持一鍵。

## 已知問題

- **瀏覽器保留鍵路由未驗證**：跨來源 iframe ＋ 頂層 Keyboard Lock ＋ 原生全螢幕的
  組合情境（CDP 合成鍵不走瀏覽器保留鍵路由）→ 列為未驗證，不宣稱通過。
- **雲端實機往返與多裝置 409 未實演**：standalone 沒有雲端環境；409 三選一、
  requestId 重送與「標題上採用雲端」目前只有單元／wiring 證據（無實機）。
- **疾跑取消提示只驗了「潛行」一路**：其餘原因（撞牆／飢餓／水中／飛行／攻擊命中）
  有單元測試，未逐一在瀏覽器實測文案。
- **`beforeunload` 的存檔失敗仍為靜默**（關頁面時無 UI 可提示，設計如此）。
- **音效聽感與敵對生物命中**仍屬人工驗證範疇（本批未改音效）。
