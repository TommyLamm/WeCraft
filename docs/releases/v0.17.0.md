# v0.17.0 — B14 釣魚與魚類

> 釣魚竿、六種魚與完整的釣魚循環：**3 木棍＋2 線**做出釣魚竿（耐久 64）、
> **16 格內**右鍵水面拋線、**等待 5–30 秒**、**2 秒魚訊窗口**內右鍵收線，
> **魚 85%／垃圾 10%／寶物 5%** 的戰利品分佈，生魚能**用熔爐烤熟**、六種魚都能吃。
> **存檔格式不升版**（本機 payload v6／雲端 format 4；`cloudSave` 一字未動）。
> 執行計畫：`docs/superpowers/plans/2026-11-06-wecraft-b14-fishing.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B14「釣魚與魚類」結案）。

## 新增

- **7 個新物品**（物品表 106 → **113**）：`fishing_rod`、`raw_cod`、`cooked_cod`、
  `raw_salmon`、`cooked_salmon`、`pufferfish`、`tropical_fish`。釣魚竿**耐久 64、
  堆疊 1**；魚堆疊 64。
- **1 個新配方**（配方 67 → **68**）：**釣魚竿**（3 木棍＋2 線，原版 3×3 斜向形狀
  ——高度 3 → 需工作台 3×3，2×2 背包合不出來，與原版同）。
- **拋線**：手持釣魚竿**右鍵水面**（**16 格內**）→ 浮標落在命中格的水面上。
  射線用**釣魚專用**的「水也可命中」模式——一般挖掘／放置仍照原樣穿過水面。
- **等待與魚訊**：拋線後等待 **5–30 秒**（每次拋線重新擲）→ 進入 **2 秒魚訊窗口**
  （浮標下沉、播放魚訊聲、右上提示「有東西上鉤了！右鍵收線」）→ 錯過則**魚跑掉**。
- **收線**：**魚訊窗口內**右鍵 → 漁獲進背包（背包滿時**掉在腳邊**），
  **扣 1 耐久**（創造模式不扣；**最後一次使用把竿用壞時，魚仍然拿到手**）。
  空收線與錯過魚訊**不扣耐久**。
- **戰利品**：**魚 85%**（cod 60／salmon 25／pufferfish 13／熱帶魚 2）、
  **垃圾 10%**（木棍×2／線／腐肉／骨頭／皮革／橡木板材×4）、
  **寶物 5%**（鐵錠／金錠／鑽石／弓／皮革靴）。
- **食物與冶煉**：**六種魚都能吃**——生鱈魚 2／0.4、烤鱈魚 5／6、生鮭魚 2／0.4、
  烤鮭魚 6／9.6、河豚 1／0.2、熱帶魚 1／0.2；**生魚可放進熔爐烤熟**
  （生鱈魚 → 烤鱈魚、生鮭魚 → 烤鮭魚）。
- **一個新進度**（累計 **20** 項）：取得任一種**生魚** →「釣魚翁」（熟魚不解鎖）。
- **右鍵分流**：**線已拋出時右鍵一律收線**（即使瞄的是空氣或方塊），不會重新拋線、
  開介面或放置方塊；**拋線**排在工作台／熔爐／箱子／床／TNT 的使用**之後**、
  拉弓與進食**之前**——不會吞掉那些互動。
- **取消條件**：換格（手上不再拿竿）／打開面板／死亡／離開遊戲／**離浮標超過
  16 格**／**浮標那一格的水不見了** → 釣魚線消失（不產出漁獲）。
- **視覺與音效**：**釣魚線＋浮標**（線是兩點直線，魚訊時浮標下沉 0.05 格）、
  **潑水聲**（拋線與收線）與**魚訊聲**（兩聲短促的提示音）——皆為程序合成的近似音。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **新物品是字串 id**（`fishing_rod`、`raw_cod`…）：舊版讀到不認識的 id → 直接清洗
   掉，**不崩**。
3. **回退到 0.16.0 時**：
   - 舊版的 `ITEM_IDS` 不認識 7 個新 id → **背包／箱子裡的釣魚竿與六種魚會被
     清洗掉**；回到 0.17.0 後**不會自動回來**。
   - 其餘存檔內容照舊可讀（本批沒有新增 block id，也沒有新的存檔欄位）。
4. 0.16.0（含）以前的存檔在新版可正常讀取；**沒有新增其他回退限制**。
5. **浮標與魚訊不跨存檔**（與引信 TNT／敵對生物同一級的暫態）——存檔讀檔後不會
   留下幽靈釣魚線。

## 已知問題／簡化

- **沒有原版的「開放水域」判定**：原版要求浮標落在開闊水域（5×4×5 的開闊與水深
  判定）才釣得到魚；本作**瞄到任何水面格就能拋線**。
- **沒有天氣／幸運加成**：**等待 5–30 秒**與**魚訊窗口 2 秒**是固定的自訂值。
- **浮標沒有物理漂移**：浮標**靜止**在命中點、線是**兩點直線**（沒有重力下垂、
  沒有魚群實體，也沒有浮標隨波上下起伏的動畫）。
- **垃圾與寶物是既有物品池的簡化表**：原版包含碗、皮革靴、命名牌、鸚鵡螺殼、
  附魔書等；本作只從**既有物品**挑。
- **釣魚竿沒有附魔**（無餌釣 Lure、無海洋祝福 Ocean's Blessing）、**沒有魚桶**
  （本作沒有水桶物品，因此也沒有熱帶魚桶）。
- **第三人稱時釣魚線從相機附近出發**（竿尖的近似位置），不是從手持模型精準長出。
- **音效是程序合成的近似音**（低通白噪音的「噗通」＋兩聲短正弦的魚訊；
  原版是取樣音）。
- 舊版（0.16.0）回退時新物品的清除行為見上節第 3 點。
