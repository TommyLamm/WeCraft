# v0.20.0 — B17 經驗與附魔

> 經驗來了：**挖礦／擊殺／冶煉／釣魚都會冒出經驗球**，球會**自動磁吸並被吸收**，
> 點數在吸收時才入帳；經驗條與等級顯示在**熱鍵欄上方**（創造模式隱藏，F3 多一行
> `Xp:`）。經驗有了用途——**附魔台**（1 金錠＋2 鑽石＋4 石頭）右鍵開啟面板，
> **以等級兌換五種附魔**（效率／鋒利／保護／耐久／幸運；**每件物品最多一個附魔、
> 可再花等級升級**，附魔以紫色 `✦` 前綴顯示）。
> **存檔格式不升版**（本機 payload v6／雲端 format 4；`game.json` 的 `cloudSave`
> 一字未動；玩家經驗 `xp` 與堆疊附魔 `ench` 都是**附加欄位**；新 block id 49
> append-only）。
> 執行計畫：`docs/superpowers/plans/2026-11-11-wecraft-b17-xp-enchanting.md`；
> 規格：`docs/superpowers/specs/2026-11-11-wecraft-xp-enchanting-design.md`
> （母規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md` §B17
> 「經驗與附魔」結案）。

## 新增

- **經驗模型（`src/core/experience.ts`）**：`{ level, xp }`；等級曲線沿用原版 Java
  分段公式（`level<16` → `2L+7`、`level<31` → `5L−38`、其餘 → `9L−158`），
  **上限 100 級**（滿等後多餘點數丟棄）；`addExperience`／`spendLevels`／
  `experienceProgress`／`normalizeExperience` 全部純函式、非有限輸入安全。
- **經驗球實體（`src/world/xp-orbs.ts`）**：`spawnXpOrbs`（就近合併、上限 **128** 顆、
  單球值上限 32767）與 `stepXpOrbs`（重力／水平阻力／地面吸附／單次反彈、
  0.5 秒後開始**磁吸**、`ORB_PICKUP_RADIUS` 內**吸收**、超時 300 秒回收）。
  **點數只住在球裡、由玩家吸收時才入帳**——未吸收的點數會消失。
- **經驗球渲染（`src/render/xp-orbs.ts`）**：小發光方塊、浮動與自轉（無 WebGL 測試）。
- **經驗來源表（`src/world/xp-awards.ts`）**：煤 **1**／鐵 **1**／金 **2**／鑽石礦
  **4**（**手動挖破且可收穫**，生存）；玩家造成的擊殺——殭屍／骷髏／苦力怕／蜘蛛
  **5**、雞 **1**／豬 **2**／羊 **2**／牛 **3**（近戰或玩家箭；爆炸擊殺不算）；
  熔爐**取出**冶煉成品每件 **1**；釣魚——魚 **2**／垃圾 **1**／寶物 **5**。
  **創造模式不發經驗**。
- **經驗 HUD（`src/ui/xp-hud.ts`）＋ F3**：熱鍵欄上方的綠色經驗條＋置中等級數字
  （**創造模式兩者都隱藏**，與血條一致）；F3 多一行 `Xp: L<level> <xp>/<need>`
  （插在 `Weather:` 之後、`Triangles:` 之前）。單一顯示路徑 `setExperience`。
- **附魔純邏輯（`src/core/enchantments.ts`）**：五種附魔——**效率**（上限 5）、
  **鋒利**（5）、**保護**（4）、**耐久**（3）、**幸運**（3）；相容表、`rollEnchantOffers`
  （未附魔 → 1／2／3 級三檔；已附魔未達上限 → 單一升級選項；達上限／不可附魔 → 空）、
  `applyEnchant`、`normalizeEnchantment`／`sanitizeEnchantFor`、五個效果查詢函式與
  顯示名（`Efficiency III`、`stackName ✦ Efficiency III`）。
- **`ItemStack.ench` 貫穿存檔鏈**：背包 ctor／`addItem`／`setSlot`、背包 UI 的右鍵
  手動重建、合成格 staging／歸還、掉落物（`DropEntity`／`spawnDrop`／`pickup`）、
  盔甲 `normalizeArmorSet`、塊實體（箱子／熔爐）、雲端 `normalizeCloudStack`、
  `giveItem`／`dropSelected`／`dropAtPlayer`、熔爐取物／歸還——**所有堆疊重建點都保留
  附魔**；`addItem` 只在附魔相同時合併。
- **附魔台**：方塊 **`BLOCK.ENCHANTING_TABLE`（block id 49）**（硬度 5、爆炸抗性 1200、
  三面 tile：top `50`／side／bottom `51`、`TILE_COUNT = 52`、音效群組 `stone`、
  暗紫＋金色角飾貼圖）；物品 **`enchanting_table`（第 116 個 ItemId）**；
  **配方 69 → 70**（3×3：上排中央金錠、中排鑽石／石頭／鑽石、下排三石頭
  ＝**1 金錠＋2 鑽石＋4 石頭**）。
- **附魔面板（`src/ui/enchanting.ts`）**：右鍵附魔台開啟（**生存與創造皆可**）——
  顯示手持物件、目前等級、選項按鈕（`Efficiency III — 3 級`）與提示訊息；等級不足
  → `disabled`；點選項 → 驗證（等級足夠、選項仍有效）→ 扣等級（**創造免費**）→
  `applyEnchant` → 刷新面板＋HUD，並發 `enchanted` 進度事件；Esc／點背景關閉並重新
  鎖定指標（與熔爐同型）。附魔作用對象＝當下選取的熱鍵格。
- **效果接線**：挖掘 `toolSpeed()`（**只在工具種類正確時** +效率）、近戰
  `meleeDamageFor()`（+鋒利）、減傷 `absorbArmorDamage()`（+保護、合計上限 80%）、
  `damageStack()`（先擲耐久、可注入 rng）、`spawnBlockDrop()`（四種礦物追加幸運件數）。
- **兩個新進度**：**附魔師**（附魔一件物品）、**經驗老到**（達到 10 級）——總數
  **20 → 22**。
- **`?xp=<n>` 查詢參數**（驗收／展示專用，與 B15 `?weather=` 同級）：開局把生存經驗
  設為 `n`（正規化後套用）；正常遊玩不帶參數。
- **存檔**：玩家經驗走本機 `player.xp`（`SavePayloadV6` 附加欄位）與雲端 `CloudData.xp`
  （附加欄位），兩邊皆 `normalizeExperience`；`ItemStack.ench` 走完整存檔鏈。

## 修正

- **無對玩家可見的修正**。本批是純新增功能；實作期間的內部調整：
  - **被動生物的玩家箭殺經驗**（commit `0030a70`）：被動生物的每幀死亡過濾支一律
    傳 `killedByPlayer: false` → 弓獵雞／豬／羊／牛原本 **0 經驗**；改在
    `applyPlayerArrowHit` 的傷害當下發點（**不**記進敵對生物的 `playerArrowKills`
    id 空間——兩邊 id 可能數值相同）。
  - **礦物經驗補上「可收穫」閘門**（同一 commit）：礦物經驗與掉落共用同一道
    `canHarvest` 閘門——徒手挖石頭／鐵礦**不發點**（spec §6：「手動挖破**且可收穫**」）。
  - **經驗 HUD 在讀檔／雲端還原後依正確模式顯示**（commit `6a72936`）：兩條還原路徑
    （`continueGame`／`applyCloudData`）的 `setExperience(...)` 原本排在 `currentMode`
    指派**之前** → 創造→生存的還原會把經驗條留在隱藏；現移到 `currentMode` 指派之後
    （與 `setVitals` 同一條規則）。以 `main.wiring.test.ts` 的 AST 釘子固定。
  - `main.wiring.test.ts` 補上附魔面板開啟路徑與 `onChoose` 守門（**等級不足不得免費
    附魔**）的接線釘子（commit `5ba69e6`）。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **玩家經驗 `xp` 是附加欄位**：本機 `player.xp`、雲端 `CloudData.xp`，舊版讀到會
   **忽略**（回到 0 級）；`loadGame`／`acceptCloudData` 一律以 `normalizeExperience`
   清洗。**經驗球本身不跨存檔**（暫態，與掉落物同級）。
3. **物品附魔 `ench` 是附加欄位**：所有堆疊重建點都保留它；舊版讀到會被
   `sanitizeStack` **清洗掉**。
4. **新方塊 id 是 append-only（49）**：回退到 0.19.0 時附魔台顯示為**空氣**（水源等
   既有方塊不受影響）；**新物品 id `enchanting_table` 會被舊版清洗** → 背包／箱子裡的
   附魔台消失。
5. **回退到 0.19.0 時**：`xp` 被忽略、`ench` 被清洗 → **經驗與附魔消失**，存檔本身
   照常可讀；**沒有新增回退阻擋**（與盔甲／重生點同級的明示限制）；回到 0.20.0 後
   經驗與附魔**不會自動回來**。
6. 沒有新增存檔欄位的升版；0.19.0（含）以前的存檔在新版可正常讀取。

## 已知問題／簡化

- **附魔台配方偏離原版**：本作 **1 金錠＋2 鑽石＋4 石頭**（原版 4 黑曜石＋2 鑽石＋
  1 書）——**本作沒有黑曜石、書與青金石**（刻意未實作）。
- **每件物品最多一個附魔**（可花等級把同一個附魔升到上限）；**沒有鐵砧、附魔書、
  附魔台等級隨書架提升、隨機重骰**——選項固定為 1／2／3 級三檔；**創造模式附魔免費**。
- **沒有附魔光澤（glint）動畫與附魔粒子**——以物品名的紫色 `✦` 前綴與面板文字代替。
- **保護的公式簡化**：每級視為 **+1 護甲點**（沿用本作「每點 4%」的減傷公式、合計
  上限 80%）；原版是每件盔甲各自的 EPF 百分比減傷。
- **耐久的公式簡化**：每次扣耐久有 **L/(L+1)** 機率不扣（L1 50%／L2 66.7%／L3 75%）；
  原版依物品種類分公式（工具是 60%+40%/(L+1)）→ 本作比原版工具略弱。
- **幸運的公式簡化**：**floor(L/2) 保證＋（奇數級 50%）再 +1**（四種礦物）；原版是
  依掉落表逐件抽機率。
- **效率與鋒利是自訂的近似公式**：效率 **+（L²+1）** 挖掘速度（**只在工具種類正確時**
  生效）、鋒利 **+（1+0.5(L−1)）** 近戰傷害。
- **死亡不清經驗**：本作死亡**保留**經驗（與「死亡保留物品」同一條既有決策）；
  原版死亡會噴出部分經驗球。
- **經驗上限 100 級**：滿等後多餘的點數直接丟棄；原版沒有這個上限。
- **花等級附魔會清空當前進度條**（花掉的等級連同當前級內的點數一起歸零）；原版不會。
- **經驗球是暫態、不跨存檔**（與掉落物、敵對生物同一級）：離線或重開遊戲會消失，
  **未吸收的點數會消失**（超時 300 秒回收，或球數達上限 128 顆時改與最近的球合併）。
- **經驗來源是簡化表**：只有四種礦物、四種敵對生物、四種被動生物、熔爐**取物**與
  釣魚；**爆炸摧毀的礦物與噴出的熔爐內容不發經驗**（只有手動挖破且可收穫、玩家造成
  的擊殺才發）；**創造模式不發經驗**。
- **`?xp=<n>` 是驗收／展示用的查詢參數**；正常遊玩不帶參數。
- **未實作的原版周邊**：生怪磚、村莊交易、幸運以外的新附魔、附魔書合成。
