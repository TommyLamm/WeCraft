# v0.18.0 — B15 天氣與雷雨

> 天氣會自己走：**晴朗 90–210 秒 → 下雨 45–120 秒 →（35% 機率）雷雨 20–60 秒**
> → 再回到下雨／放晴。雨天的**陰天天色**、**跟著相機的雨絲**、**雨聲**、**雷電閃光與
> 雷聲**，以及四個明示的玩法效果（雨天**釣魚等待縮短**、**耕地保持濕潤**、
> **不死系不會被曬傷**、**雷雨時白天也能睡覺**）。
> **存檔格式不升版**（本機 payload v6／雲端 format 4；`cloudSave` 一字未動；
> **天氣是暫態、不進存檔**）。
> 執行計畫：`docs/superpowers/plans/2026-11-07-wecraft-b15-weather.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B15「天氣與雷雨」結案）。

## 新增

- **三態天氣**：晴朗／下雨／雷雨，會**自己轉場**——晴 **90–210 秒**、雨 **45–120 秒**、
  雷雨 **20–60 秒**；雨結束時 **35%** 接雷雨、其餘放晴；雷雨結束後先回到一段雨。
  轉場時右上角提示**「開始下雨了／雷雨來了／放晴了」**。
- **雨絲**：**600 條**雨線跟著相機落下（半徑 14 格、下落速度 18–26 格/秒），
  雨天／雷雨都會下；**玩家在室內／洞穴／水下時整片隱藏**（不會從窗戶看到外面的雨）。
- **陰天天色**：雨天與雷雨會把天色壓暗（雨天 55%、雷雨 72% 的陰影強度），地表亮度
  乘 **0.82**（雨天）／**0.68**（雷雨）；雷電閃光會短暫提亮（閃光 0.18 秒）。
- **雷電**：雷雨期間會打雷閃光——**第一次閃電延遲 1–4 秒**、之後每隔 **4–12 秒**
  一次，**閃光與雷聲同時**發生。
- **音效**：**雨聲**（低通白噪音的迴圈，雨天／雷雨時開、晴天停）與**雷聲**
  （低頻隆隆聲＋下滑正弦）。皆為**程序合成的近似音**。
- **四個玩法效果**（本作**自訂的簡化規則**，不是原版規則）：
  - **雨天釣魚等待縮短 20%**：5–30 秒 → **4–24 秒**（魚訊窗口仍是 2 秒）；
  - **雨天耕地視為濕潤**：與水源同一條 **25%** 成長門檻（原本乾燥耕地是 10%）；
  - **雨天不死系不會被日光曬傷**：殭屍／骷髏在露天白天**不再著火**（已在燃燒的會
    熄火、不再扣血）；
  - **雷雨時白天也能睡覺**：右鍵床在雷雨中白天可以睡（距離與怪物阻擋規則不變）。
- **F3 調試疊層多一行 `Weather:`**（`clear`／`rain`／`thunder`），位置在 `Biome:`
  與 `Triangles:` 之間。
- **驗收用的查詢參數**：`?weather=clear|rain|thunder` 可**鎖定**天氣（不自動轉場，
  但雷雨仍會打雷閃電）；正常遊玩不帶參數。

## 修正

- 無對玩家可見的修正。本批是純新增功能；實作期間的內部調整：
  - `world/weather.ts`（新純邏輯模組）、`render/weather.ts`（雨絲）、
    `audio/` 的雨聲與雷聲（走專屬的 `setWeather`／`playThunder`，**既有 7 個
    `audio.play` 呼叫點一個都沒變**）；
  - 四個既有純邏輯模組各加一個**可選**的天氣參數（`rollFishingWait(rng, raining)`、
    `growWheatBatch({ raining })`、`bedUse({ thunder })`、`SunBurnCtx.isRaining`）
    ——**省略參數時的行為與 0.17.0 完全相同**；
  - 天穹與霧／背景各自套一次天氣色（天穹保留「原始天色」的既有決定，晴天天色
    與 0.17.0 一致）。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **天氣不進存檔**（本機與雲端都沒有天氣欄位）——天氣是**暫態**，與引信 TNT／
   敵對生物同一級：**新局／繼續遊戲／雲端套用後都回到晴朗**。
3. 沒有新增物品、方塊或配方 → **物品表 113、配方 68 不變**，舊存檔的物品與方塊
   一律照讀。
4. **回退到 0.17.0 時**：存檔本身**照常可讀**（沒有新欄位、沒有新 id）→ **沒有新增
   回退限制**；只是回退後看不到天氣。
5. 0.16.0（含）以前的存檔在新版可正常讀取。

## 已知問題／簡化

- **雨絲只跟相機、不逐格遮蔽**：沒有原版的逐格降雨判定——雨不會真的擋住視線或方塊
  光照；玩家在**室內／洞穴／水下時整片隱藏**（**不會從窗戶看到外面的雨**；判準是
  相機格天空光 **15＝頭頂整柱無不透明方塊**，樹葉／玻璃是透明的 → 下方仍看得到
  雨絲，與本作「透明方塊不過濾天空光」的既有簡化一致）。
- **雷電只有閃光與雷聲**：**不會打中生物、不會起火、不會破壞方塊**；沒有降雨粒子
  濺射、沒有積水、沒有雪。
- **雷聲與閃光同時播放**：沒有原版依距離而來的雷聲延遲。
- **天氣是暫態、不跨存檔**：重開／繼續／雲端套用後回到**晴朗**。
- **雨聲與雷聲是程序合成的近似音**（原版是取樣音）；**沒有天氣預報 UI**
  （只有轉換提示與 F3 的 `Weather:` 列）。
- **玩法效果是自訂的簡化規則**：雨天釣魚等待 ×0.8、雨天耕地濕潤 25%、雨天不曬傷、
  雷雨時白天能睡——**都不是原版的規則**（原版是雨天魚種機率、作物不受雨害、
  雷電打擊生物並起火等）。
- **只有三態、沒有機率表與區域差異**：轉場間隔是固定的自訂值，沒有原版按維度／
  生物群系調整的天氣機率，也沒有沙暴／雪暴。
- **`?weather=` 是驗收／展示用的參數**：鎖定後不自動轉場（雷雨仍打雷）；正常遊玩
  不帶參數。
