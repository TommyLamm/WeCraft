# v0.16.0 — B13 農業與骨粉

> 鋤頭、耕地、小麥、骨粉與麵包：**五種鋤**（各正／鏡像配方）、**耕地方塊**、
> **小麥四階段**、**每 5 秒**的成長判定（濕潤 25%／乾燥 10%）、**骨粉一次催熟
> 2 階段**、成熟收成 1 小麥＋0–3 顆種子。**存檔格式不升版**（本機 payload v6／
> 雲端 format 4；`cloudSave` 一字未動）。
> 執行計畫：`docs/superpowers/plans/2026-11-05-wecraft-b13-farming.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B13「農業」結案）。

## 新增

- **耕地方塊**（block id **36**）與**小麥四階段**（block id **37–40**，
  tile 45–49、`TILE_COUNT=50`）：兩者都是**狀態方塊、沒有物品形式**、不進
  `PLACEABLE`（創造清單拿不到、也不能從背包拿出來放置）——只能靠鋤地與播種產生。
- **9 個新物品**（物品表 97 → **106**）：`wheat_seeds`、`wheat`、`bread`、
  `bone_meal`，以及五種鋤（木／石／鐵／金／鑽）。鋤的耐久與同材質工具相同
  （木 59／石 131／鐵 250／金 32／鑽 1561）。
- **12 個新配方**（配方 55 → **67**）：
  - 五種鋤各有**正／鏡像**兩種形狀（2 材質＋2 木棍，橫刃在左或右；高度 3 →
    需工作台 3×3，2×2 背包合不出來，與原版同）。
  - **麵包**：3 顆小麥橫排（寬度 3 → 需工作台 3×3）。
  - **骨粉**：1 根骨頭 → **3 個骨粉**（shapeless，2×2 背包即可合成）。
- **鋤地**：手持鋤頭**右鍵泥土／草地**（上方須是空氣）→ 該格變成耕地，
  **扣 1 耐久**（創造模式不扣；最後一次使用仍完成鋤地）。
- **播種**：手持**小麥種子右鍵耕地**（上方須是空氣）→ 耕地上一格長出
  小麥階段 0，**消耗 1 顆種子**。
- **骨粉催熟**：手持**骨粉右鍵小麥** → **一次推進 2 階段**（上限成熟），
  **消耗 1 個骨粉**；對成熟小麥或非小麥方塊不生效、不消耗。
- **成長判定**：小麥**每 5 秒**判定一次（主迴圈的固定節拍，非原版隨機 tick）：
  - 條件：**光照 ≥ 9**（內部天空光或方塊光的大者）、**下方是耕地**；
  - **水源水平 4 格內（垂直 ±1）** → **濕潤 25%**，否則**乾燥 10%**；
  - 每批最多推進 **64 株**，超過時以**游標輪替**（株數多的田不會只有前幾株長）。
- **收成**：成熟小麥 → **1 小麥＋0–3 顆小麥種子**；未成熟小麥 → **1 顆種子**
  （手動破壞；爆炸走單一物品路徑，見〈已知問題〉）。
- **短草 12.5%** 掉 1 顆小麥種子（原版機制）；**耕地挖掉掉泥土**。
- **麵包可吃**：食物值 **5**、飽食度 **6**（原版數值）。
- **兩個新進度**（累計 **19** 項）：取得小麥 →「小麥農夫」；取得麵包 →「麵包師」。
- **右鍵分流**：農業動作（鋤地／播種／骨粉）在**一般放置之前**執行，但**在**
  工作台／熔爐／箱子／床／TNT 的開啟、拉弓與進食**之後**——不會吞掉那些互動。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **新 block id 只追加**（36–40；append-only，進 `modified` overlay）：
   舊版讀到不认识的 id → fallback 空氣、**不崩**。
3. **回退到 0.15.0 時**：
   - 舊版把 36–40 當空氣 → **耕地與小麥會消失**（種小麥的耕地回到泥土或空氣）；
   - 舊版的 `ITEM_IDS` 不認識 9 個新 id → **背包／箱子裡的種子／小麥／麵包／
     骨粉／五種鋤會被清洗掉**；回到 0.16.0 後**不會自動回來**。
   - 其餘存檔內容照舊可讀。
4. 0.15.0（含）以前的存檔在新版可正常讀取；**沒有新增其他回退限制**。

## 已知問題／簡化

- **耕地是滿格方塊**（原版是 15/16 高的薄板），**沒有濕潤貼圖變化**——濕潤只影響
  成長率（25%／10%），看起來與乾燥耕地完全一樣。
- **成長是固定 5 秒一批**的判定（原版是隨機 tick），沒有原版的隨機成長步進。
- **無耕地踩踏退化**（走回耕地不會變回泥土）、**無作物踩踏**、**無村莊／
  堆肥桶／鋤頭附魔**。
- **骨粉只能催熟小麥**，不能催花草／樹木。
- **爆炸對小麥只掉單一物品**（成熟 1 小麥／未成熟 1 顆種子），**沒有手動收成的
  0–3 顆種子加成**。
- **小麥沿用 cross 型植被的「可被放置取代」規則**：對著小麥放方塊會直接覆蓋
  （**不掉落**）——原版作物不可被取代。
- **小麥與耕地沒有物品形式**：創造清單拿不到、也不能從背包拿出來放置。
- **音效沿用既有程序合成的挖掘聲**（`dig`／`dirt`），本批未新增農業專屬音效。
- 舊版（0.15.0）回退時耕地／小麥與新物品的清除行為見上節第 3 點。
