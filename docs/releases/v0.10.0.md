## 存檔格式與相容性提示

1. **雲端 format 3 的回退限制**：0.10.0 寫出的雲端資料是 format 3，**0.9.0（只宣告可讀 format 1、2）讀不到** → 平台會以 `SAVE_FORMAT_INCOMPATIBLE` 擋下不相容的回退。要回到 0.9.0 必須先在 0.10.0 重新開局（雲端槽會被改寫）。
2. **本機 payload v5 的回退限制**：0.10.0 寫出的本機存檔是 v5，**0.9.0 只接受到 v4 → 讀不到（顯示成「沒有存檔」）**；資料本身沒被刪除，升回 0.10.0 即復原。這與 B5 的 v3→v4 升版同型。
3. **向前相容**：本機 payload 升 **v5**（堆疊可帶 `dur`）；v1／v2／v3／v4 舊存檔照讀並遷移，**舊存檔裡的工具載入後是滿耐久**（不會一拿出來就壞）。雲端格式升 **3**（`readableFormats:[1,2,3]`、`writeFormat:3`）；舊的 format 1／2 雲端進度會在讀入時自動遷移（工具補上滿耐久），下一次檢查點即以 format 3 寫回。
