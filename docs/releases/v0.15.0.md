> 裝備、護甲點數減傷、受擊耐久、護甲條 HUD 與第三身色塊外觀。**存檔格式不升版**

## 新增

- **16 件盔甲**（物品表 81 → **97**）：皮革／鐵／金／鑽石 × 頭盔／胸甲／護腿／靴子。
  顯示名由 id 自動推導（`golden_chestplate` → Golden Chestplate）。
- **合成**（配方 39 → **55**）：原版形狀——頭盔 5 塊、胸甲 8 塊、護腿 7 塊、
  靴子 4 塊（胸甲／護腿需工作台 3×3；頭盔／靴子可在 2×2 背包合）。
- **背包裝備格**：生存模式 E 面板左上四格；沿用既有游標堆疊模型（左鍵整疊、
  右鍵半堆疊）；**只有對應部位的盔甲放得進去**（錯誤物品留在游標上）。
  創造模式不顯示裝備格（也穿不上盔甲）。
- **減傷**：護甲點數照原版（皮革 7／鐵 15／金 11／鑽石 20）；
  `damage × (1 − min(20, 點數) / 25)`，四捨五入、正傷害至少 1（最高 80%）。
  適用於生物近戰／骷髏箭／蜘蛛／爆炸／仙人掌；**墜落與飢餓刻意不減免**。
- **耐久**：皮革 55／80／75／65、鐵 165／240／225／195、金 77／112／105／91、
  鑽石 363／528／495／429。每次上述傷害事件，**每個已裝備部位各扣 1**；
  歸零即壞（該部位消失＋「盔甲損壞」toast），同一次傷害仍先算完減傷。
- **護甲條 HUD**：血量條上方 10 個盾牌圖示（每圖示 2 點，偶數點顯示半格）；
  0 點或創造模式時整條隱藏。
- **第三身外觀**：玩家模型新增 4 片盔甲色塊（頭／胸／腿／腳），依材質上色
  （皮革棕／鐵藍灰／金黃／鑽石灰青），第一人稱不顯示。

## 修正

- 無。本批是純新增功能。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `game.json` 的 `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. `player.armor`（本機）與 `armor`（雲端）是**附加欄位**：
   - 舊記錄沒有這個欄位 → 載入後是**四格空**（不是壞檔、不整包拒收）。
   - 單格壞掉（錯誤部位／非法耐久）→ **只丟那一格**，其餘保留。
3. **回退到 0.14.0 時**：舊版忽略 `armor` 欄位（穿在身上的盔甲消失），且
   `ITEM_IDS` 不認識 16 個新 id → 背包／箱子裡的盔甲物品會被清洗掉；
   回到 0.15.0 後盔甲格與物品**不會自動回來**。其餘存檔內容照舊。
4. 0.14.0（含）以前的存檔在新版可正常讀取；**沒有新增其他回退限制**。

## 已知問題／簡化

- **無盔甲韌性**：減傷只有「每點 4%、上限 80%」這條簡化公式（原版另吃韌性與
  傷害值）。
- **沒有鎖鏈與獄髓**；**沒有盔甲紋樣、修補、鐵砧、附魔**。
- **盔甲不減免墜落與飢餓傷害**（原版亦不減免這兩類，但本作其餘傷害來源也一體
  套用簡化公式）。
- **外觀是四片純色方塊**（無貼圖、無手臂／帽簷細節）；物品圖示是像素近似。
- **創造模式沒有裝備格**：切到創造時盔甲仍穿在身上（第三身可見），但 HUD 護甲條
  隱藏、世界傷害也不作用；切回生存原樣恢復。
- **盔甲損壞只有 toast**（無原版 `entity.item.break` 的專屬音效；音效仍走既有
  程序合成路徑——本批未新增盔甲音效）。
- 舊版（0.14.0）回退時盔甲與盔甲物品的清除行為見上節第 3 點。
