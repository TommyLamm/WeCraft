## 存檔格式與相容性提示（請先讀這段）

1. **本機存檔 payload 升 v4**（36 格背包語義）。v1／v2／v3 舊存檔照讀並自動遷移：
   **舊的 9 格會落在熱鍵列、其餘 27 格留空**；兩模式的 stash 也升為 36 格，物品不丟失。
2. **雲端格式升 2**（`readableFormats:[1,2]`、`writeFormat:2`；`game.json` 同步宣告）。
   format 1 的舊雲端進度**讀入時自動遷移**成 36 格（同上規則），下一次檢查點即以
   format 2 寫回（1→2 的升級路徑）。
3. **回退限制**：0.8.0 寫出的雲端資料是 format 2，**0.7.0（只宣告可讀 format 1）
   讀不到** → 平台會以 `SAVE_FORMAT_INCOMPATIBLE` 擋下不相容的回退。要回到 0.7.0
   必須先在 0.8.0 重新開局（雲端槽會被改寫）。
4. **舊存檔載入時會跳一次「地形已改變」提示**：本批新增礫石與礦脈深度帶，
   `WORLDGEN_VERSION` 由 1 升 2——本作從不保存區塊，載入時整片地形由 seed 重新生成，
   建築可能浮空、埋入或入水（玩家與生物的既有行為，見〈已知問題〉最後兩條）。

## 已知問題

- **礦脈是逐格密度模型**，不是原版的成團 blob——只對齊了深度分佈的形狀與帶界
- **煤炭分佈未對齊原版**（原版是近地表三角帶、Y=0 以下無煤；本作維持均勻密度 1/120，
  讓低窪地形保住燃料來源——刻意偏離）
- **花與草會掉落自身**（原版需要剪刀／絲綢觸碰才掉；本作為了可再生刻意偏離）
- **冰沒有取得途徑**（原版需絲綢觸碰；本作無絲綢觸碰 → 只有創造模式拿得到）
- **金／鑽石沒有方塊形式**（9 個金錠合成金塊、9 顆鑽石合成鑽石塊尚未實作）
- **背包沒有滑鼠拖曳的多格搬運**（以點擊選取→點擊放置代替；右鍵半堆疊／放 1 已支援）；
  工作台 3×3 來源列預設只顯示熱鍵列 9 格（工作台面板可看全部 36 格）
- **創造物品清單沒有分類頁籤與搜尋**（全物品平鋪、可捲動）
- **工具無耐久與修補**（B7 處理；含本批新工具）
- **音效**：被動生物叫聲／受傷／死亡聲仍未實作（B4 裁決跳過、延後）
- **瀏覽器層未驗證項**（承襲各批紀錄）：`Ctrl+W` 等瀏覽器保留鍵、平台原生全螢幕與
  頂層 Keyboard Lock 的組合情境、真 worker 位元組一致性——自動化探針無法可靠複刻
- **讀檔後動物（與玩家）可能短暫懸空**：區塊還沒生成完成時腳下沒有地面；區塊載入、
  生物活躍後會自行落地（既有行為）
- **跨地形版本更新（0.7.x → 0.8.0）不還原舊動物**：`WORLDGEN_VERSION` 改變 → 地形
  整片改觀、舊座標不可信（可能埋進方塊裡動不了）→ 舊存檔的 `passiveMobs` 不套用到
  場上（資料仍在存檔裡）；動物之後白天會自然重生（全場上限 12）
- **雲端回退限制**：0.8.0 的雲端槽會變成 format 2，0.7.0 讀不到（平台擋不相容回退）——
  見最上面的〈存檔格式與相容性提示〉
