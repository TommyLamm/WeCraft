# v0.14.0 — B11 TNT 與打火石

> TNT 方塊＋打火石：放好 TNT、打火石點燃、**4 秒引信**、**威力 4** 爆炸、
> **100% 掉落**、可**連鎖引爆**——把 B9 的「火藥暫無用途」接進循環，並補上 B9
> 留下的**爆炸音效**（TNT 與苦力怕共用）。**存檔格式完全不升版**
> （本機 v6／雲端 format 4 不變；TNT 是 block id 35 的 append-only 方塊、
> 新物品是字串 id）。
> 執行計畫：`docs/superpowers/plans/2026-11-03-wecraft-b11-tnt.md`；
> 規格：`docs/superpowers/specs/2026-10-18-wecraft-parity-design.md`（§B11）。

## 新增

- **TNT 方塊**（block id 35、tile 43／44）：硬度 **0**（任何工具瞬破）、
  爆炸抗性 **0**、掉自身、堆疊 64、音效材質 **grass**（全部照 minecraft.wiki/TNT，
  2026-11-03 查證）；紅底白帶「TNT」像素貼圖（頂面白框＋中央引信孔）。
- **合成**：TNT ＝ **5 火藥＋4 沙** 3×3 棋盤（火藥在角與中心、沙在邊）；
  **打火石** ＝ 鐵錠＋燧石（shapeless、耐久 **64**、堆疊 1）。物品表 79 → **81**、
  配方 37 → **39**。
- **點燃**：**手持打火石右鍵 TNT** → 方塊換成**引信 TNT 實體**（碰撞盒 0.98×0.98、
  受重力、引信 **80 tick ＝ 4 秒**、起爆瞬間向上拋 **+4 格/秒**＋隨機水平 0.4 格/秒）；
  **只有點燃成功才扣 1 耐久**（創造模式不扣）；已點燃的格子再點是 no-op
  （不重複扣耐久、不生出第二顆實體）。
- **爆炸**：威力 **4**、爆炸中心＝實體位置 **+0.06125** 格（原版）；
  **被炸掉的方塊 100% 掉落**（原版 "always drop their usual items"；苦力怕維持
  1/威力——`ExplosionCtx.dropChance` 參數化）。
- **連鎖引爆**：被爆炸波及的 TNT 轉成引信實體（隨機 **0.5–1.5 秒**後引爆；
  本作上限 **32 顆**／單批，超出者不誘爆、照 100% 規則掉成道具）。
- **渲染**：引信貼圖每 **0.5 秒**在正常與接近全白版本間切換（相位由引信推導）；
  爆炸後 mesh 同幀消失。
- **音效**（順補 B9 缺口）：點燃嘶聲（`entity.tnt.primed` 近似）＋爆炸聲
  （`entity.generic.explode` 近似：低通噪音＋低頻下滑正弦）；**苦力怕爆炸自此
  不再無聲**（兩者共用同一顆爆炸聲）；**連鎖引爆**的 TNT 也會播引信嘶聲
  （原版對任何被引爆的 TNT 都會播）。
- **死因**：新增 `tnt`——「你被 TNT 炸死了」。
- **打火石 icon**（像素圖）與 `TNT`／`Flint and Steel` 顯示名（不照 title-case
  的 id 覆寫；只影響 UI 文字）。

## 修正

- **B9 遺留缺口補上**：苦力怕爆炸原本**完全無聲**（B9 發布說明自列「爆炸音效未
  實作」）→ 0.14.0 起與 TNT 共用程序合成爆炸聲（`audio.playExplosion`）；
  **連鎖引爆**的 TNT 也補上引信嘶聲。
- **創造模式的爆炸不再產生方塊掉落**：B9 起爆炸是唯一會在創造模式灑出（且撿不起）
  地面掉落物的路徑——0.14.0 起與**挖除／容器／生物掉落**同一條「創造不灑」規則
  （生存行為完全不變；上述瀏覽器驗收的掉落數字全部是生存模式）。
- **批末獨立審查的修復**（同批未發布程式碼）：① 一個**恆真的碰撞測試**（原版
  版本落地即歸零水平速度、從未靠近牆面）改為「空中＋貼牆 0.8 格」——拿掉逐軸
  碰撞會轉紅；② 爆炸音效兩層峰值相加可能硬切（噪音 0.7＋正弦 0.5 ≤ 1.25，
  預設 master 0.8 下不切）；③ 連鎖上限的**同時存在**語意補上單元測試；
  ④ `tilePixels` 對無效 tile 的夾法兩軸一致。
- 既有測試的改動都是「改得有理」：物品／配方／tile／音效材質表成長、
  `damageHeldTool(1)` 呼叫點 6 → 7（新增點燃扣損）、`runExplosion` 由固定苦力怕
  參數化成 `{ source, power?, dropChance? }`——**沒有為了綠燈而放寬任何守門**。

## 存檔格式與相容性提示

1. **本機 payload 版本不變（v6）**、**雲端格式不變（format 4）**，
   `cloudSave` 一字未動（`readableFormats [1,2,3,4]`、`writeFormat 4`）。
2. **TNT 是 block id 35**（append-only）→ 進 `modified` overlay；**回退到 0.13.0
   時該格顯示為空氣**（未知 id 的 fallback）、**引信中的 TNT 消失**；回到 0.14.0
   後 TNT 格會再顯示（除非在 0.13.0 改動過那一格）。新物品是字串 id，
   未知 id 由 `sanitizeStack` 過濾。
3. **引信 TNT 實體不跨存檔**（與敵對生物同級）：Save & Quit 時未爆的 TNT 消失
   （存到的是方塊層級的 AIR；不會在下次載入憑空爆炸）。
4. **舊存檔照常載入**：0.13.0（含）以前的存檔在新版可正常讀取；
   **沒有新增回退限制**；既有的回退限制（0.10.0／0.11.0 段）維持不變
   （見 `docs/releases/v0.11.0.md`）。

## 已知問題／簡化

- **只支援「手持打火石右鍵 TNT」點燃**：本作沒有火系統——不能放火、不能點生物、
  沒有紅石／發射器／火焰箭；打火石**只在點燃成功時扣 1 耐久**（原版對其他使用也扣）。
- **引信 TNT 的重力用本作生物的 `MOB_GRAVITY = 32`**（原版約 16）→ 拋得比原版短、
  落地更快；**水平初速只在起爆瞬間給一次、落地即歸零**（無原版逐 tick 空氣阻力）。
- **引信 TNT 同時存在上限 32 顆**（本作自訂，防單幀爆炸風暴；**計入既有未爆的
  實體**——例如已經點燃 30 顆時，一次爆炸最多再誘爆 2 顆）；未誘爆的 TNT 照
  100% 掉落規則掉成道具。
- **已被引信的 TNT 不受其他爆炸波及**（不推擠、不加速）；爆炸的破壞判定仍是
  球形近似（見 `docs/releases/v0.12.0.md`）。
- **亮版貼圖是本作近似**：把 TNT tile 的白化複本換上去（原版是接近全白的專用
  貼圖）；TNT 貼圖本身是像素近似（紅底白帶＋「TNT」字樣）。
- **爆炸音效／引信嘶聲是程序合成的近似**（原版是 `entity.generic.explode`／
  `entity.tnt.primed` 取樣音）。
- B2–B10 中尚未完成的功能維持既有說明（見 README〈與原版的差異〉）。
