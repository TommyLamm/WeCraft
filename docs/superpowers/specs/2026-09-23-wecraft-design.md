# WeCraft — 網頁版高度還原 Minecraft 設計規格

- 日期：2026-09-23
- 狀態：已與利害關係人逐節確認
- 專案根目錄：`F:\Desktop\WeCraft`

## 1. 目標與範圍

在瀏覽器中運行、高度還原 Minecraft 現代版（1.20+ 風格）的單人遊戲。

**已確認的關鍵決策：**

| 決策點 | 選擇 |
|---|---|
| 交付策略 | **D — 分期交付**：第一期建築/探索骨架 → 第二期生存 → 第三期視覺精修 |
| 連線 | **A — 純單人**（無伺服器、無多人） |
| 美術素材 | **A — 程序生成原創貼圖**（不使用有版權的 Minecraft 素材） |
| 裝置 | **A — 桌機瀏覽器為主**（滑鼠+鍵盤、pointer lock） |
| 視覺基準 | **A — 現代版風格（1.20+）** |
| 音效 | **A — 程序生成原創音效**（Web Audio API 合成） |
| 技術方案 | **方案一 — Three.js 渲染底層 + 自寫 voxel 核心** |

**非目標：** 多人連線、行動裝置觸控、紅石、附魔/藥水、村莊 NPC、使用任何 Minecraft 官方素材。

## 2. 整體架構

```
┌─────────────────────────────────────────────┐
│  main.js  (啟動、遊戲循環、狀態機)          │
├──────────┬──────────┬───────────┬───────────┤
│  world/  │ player/  │  ui/      │  audio/   │
│ 世界與方塊│ 移動碰撞  │ HUD/選單  │ 程序音效  │
├──────────┴──────────┴───────────┴───────────┤
│  render/  (Three.js 場景、區塊網格化、霧陰影) │
├─────────────────────────────────────────────┤
│  core/  (數學、RNG、事件匯流排、設定)        │
└─────────────────────────────────────────────┘
```

### 模組職責與邊界

- **`core/`** — 純函式工具：向量/雜湊、種子 RNG、事件匯流排（`bus.emit('block:change')`）、設定存取。零依賴，可單獨測試。
- **`world/`** — 區塊資料（`Uint8Array` 存方塊 ID）、地形生成器、貪婪網格化輸出、射線方塊拾取。**不 import Three.js**，只輸出「哪些面要畫」。
- **`player/`** — AABB 碰撞、重力、跳躍、WASD、視角、挖掘/放置互動判定。不碰 DOM、不 import Three.js。
- **`render/`** — 唯一 import Three.js 的模組。吃 `world/` 的面資料建 `BufferGeometry`，管相機、霧、光照、天空。
- **`ui/`** — HUD（準星、熱鍵欄、血量飢餓、F3）、選單、背包。純 DOM/CSS，透過 `bus` 與遊戲核心通訊。
- **`audio/`** — Web Audio 合成。對外只有 `play(type, {x,y,z})`。

### 資料流（單向）

```
輸入 → player/ 更新狀態 → world/ 查詢碰撞
                          ↓
              world/ 發出 block:change 事件
                          ↓
              render/ 重建該區塊網格   ui/ 更新 HUD
```

核心原則：**`world/` 與 `player/` 不接觸 Three.js 與 DOM**，玩法邏輯可脫離瀏覽器跑單元測試。

## 3. 世界與地形生成

### 區塊結構

- 區塊尺寸 **16×16×256**（X/Z 16 格、Y 高度 256 格，還原現代版高度）。
- 每區塊一個 `Uint8Array(65536)`（16×16×256 = 65536）存方塊 ID，約 64KB/區塊。
- 已修改的區塊標記 dirty；只有 dirty 才重新網格化。

### 地形生成（種子驅動、無限世界）

1. **多層 Perlin/Simplex 噪音** — 分離高度（continentalness）、侵蝕（erosion）、山脊（ridge）三層，做出平原/丘陵/高山/山谷。
2. **生物群系** — 溫度+濕度二維噪音決定：平原、沙漠、森林、雪原、橡木林。
3. **垂直柱狀填充** — 每列由底向上：基岩 → 石頭 → 土壤 → 表層（草/沙/雪）。
4. **洞穴** — 3D 噪音閾值挖空；礦脈（煤/鐵/金/鑽石）按深度分佈。
5. **裝飾 pass** — 樹（橡木/雲杉）、仙人掌、花、草叢；位置由雜湊決定，同種子結果永遠相同。

### 載入策略

- 以玩家為中心，**視距 10 區塊**（可設定 6–16）圈出需要載入的區塊。
- 每幀限額：最多**生成 2 個區塊、重建 2 個網格**，避免卡頓；遠處區塊卸載釋放記憶體。
- 地形生成在 **Web Worker** 執行，主執行緒只收結果組網格。

### 方塊拾取與修改

- **voxel DDA 射線步進**：從相機射出，命中最近實心方塊面 → 左鍵拿掉、右鍵在命中面外側格放置。
- 修改 → 標記該區塊 + 鄰接邊界區塊 dirty → 下幀重建。

## 4. 玩家、操作與互動

### 移動與物理

- 玩家 AABB **0.6×1.8 格**（還原原版尺寸）；逐軸分離掃描（先 X 再 Y 再 Z）防穿牆。
- 重力 ~-32 格/s²、跳躍初速 ~9 格/s（跳高約 1.25 格，可上 1 格方塊）。
- 水中減速+浮力；潜行（Shift）不跌落邊緣；疾跑（Ctrl）FOV 微調。
- 創造模式：雙擊 Space 飛行，Space/Shift 升降。

### 操作表（桌機 pointer lock）

| 操作 | 功能 |
|---|---|
| 點擊畫面 | 鎖定指標進入遊戲 |
| 滑鼠 | 視角轉動 |
| W/A/S/D | 移動 |
| Space | 跳躍 / 飛行上升 |
| Shift | 潜行 / 飛行下降 |
| Ctrl | 疾跑 |
| 左鍵 | 挖掘（按住連續挖） |
| 右鍵 | 放置方塊 |
| 1–9 / 滾輪 | 熱鍵欄切換 |
| E | 背包 |
| Esc | 暫停選單（解鎖指標） |
| F3 | 調試資訊（座標、FPS、區塊） |
| F5 | 切換視角（第一/第三人稱） |

### 挖掘手感

- **破壞時間依方塊硬度**：泥土快、石頭慢、基岩不可破壞。**第一期即納入**（手感核心）。
- 挖掘中顯示**裂紋疊加層**（程序生成 10 階段破壞動畫）+ 挖掘粒子。
- 放置冷卻 ~0.25s；不可將方塊放入玩家身體佔用的格子。

### 分期對應

- **第一期（骨架）**：移動/碰撞/視角、挖掘/放置（含破壞時間）、背包+熱鍵欄、無限地形、創造模式、基礎 HUD、標題/暫停選單、程序貼圖。
- **第二期（生存）**：生存/創造切換、血量飢餓、日夜循環、怪物、合成表、死亡畫面、生存 HUD、IndexedDB 存檔。
- **第三期（視覺）**：陰影、進階光照與 AO、雲、音效精修、粒子、手持模型、死亡/進度提示完善。

## 5. UI/HUD 與視覺還原

### HUD（DOM+CSS 疊在 canvas 上）

```
┌──────────────────────────────────────────────┐
│  F3 調試（toggle）: XYZ / FPS / 區塊 / 生物群系│
│                                              │
│                   ✛ 準星                     │
│                                              │
│  ♥♥♥♥♥♥♥♥♥♥  （血量，生存模式）              │
│  🍗🍗🍗🍗🍗🍗🍗🍗🍗🍗  （飢餓，生存模式）      │
│  [1][2][3][4][5][6][7][8][9]  熱鍵欄 9 格     │
│         ↑ 選中格白框，下方顯示方塊名            │
└──────────────────────────────────────────────┘
```

- 現代版風格：深灰半透明熱鍵欄、圓角、選中格白框；心形/雞腿以 CSS pixel-art 繪製。
- 創造模式隱藏血量飢餓；熱鍵欄可放任意方塊。

### 選單

- **標題畫面** — 方塊風 logo 文字 + 「單人遊戲 / 設定 / 離開」；背景為模糊的遊戲即時畫面。
- **暫停選單（Esc）** — 半透明遮罩：繼續 / 設定（視距、靈敏度、音量）/ 回到標題。
- **背包（E）** — 3×9 儲物格 + 9 格熱鍵欄，拖曳堆疊；創造模式提供全部方塊的物品選單分頁。
- **死亡畫面（生存期）** — 紅色濾鏡、「你死了！」+ 復活按鈕。

### 視覺還原（第三期重點，架構先預留）

- 霧色隨生物群系/時間變化、天空漸層、太陽月亮方塊、方形體積雲層。
- 方塊面依方向套用亮度（頂亮底暗）+ 程序 **AO（環境遮蔽）** 讓角落有陰影感。
- 準星、第一人稱右下角手持模型。

### 程序貼圖

- 啟動時以 canvas 程序生成一張 **512×512 貼圖圖集**：草頂/草側/泥土/石頭/木頭/樹葉/沙/雪/玻璃等約 30–40 程序方塊，16×16 像素風放大。
- 頂點色承擔光照與 AO，貼圖只管顏色 — 效能佳且換皮容易。

## 6. 音效、效能與測試

### 程序音效（Web Audio API）

- **合成**：噪聲源 + 濾波器 + ADSR 包絡 → 挖土（低通短促）、挖石（帶通+金屬感）、放置（雙擊悶音）、腳步（依地面方塊變濾波頻率）。
- **環境**：低音量粉噪風聲；白天鳥叫用短振盪器掃頻；晝夜切換底噪。
- **規則**：音量設定項、頁面切至背景自動靜音；方塊事件經 `bus` 觸發 `audio.play('dig', {x,y,z})` 做距離衰減。

### 效能目標

| 目標 | 手段 |
|---|---|
| 60 FPS @ 視距 10 | 貪婪網格化合併面、單 draw call/區塊、`BufferGeometry` 復用 |
| 無卡頓載入 | Worker 生成地形、每幀限額（生成2/重建2）、時間切片 |
| 記憶體穩定 | 遠處區塊卸載、圖集共用材質、幾何體 dispose |
| 首屏快 | 程序貼圖毫秒級生成、零外部資源下載 |

### 錯誤處理

- Worker 崩潰 → 自動重建，當前佇列方塊降級回主執行緒生成（不中斷遊戲）。
- WebGL 不可用 → 相容性錯誤頁面。
- 區塊生成超時 → 重試一次；再失敗標為「虛空區塊」，不阻塞玩家。

### 測試策略

- **`core/`、`world/`、`player/` 用 Vitest**：同種子同地形斷言、AABB 碰撞案例（貼牆/角落/上格）、DDA 射線命中座標、網格化面數正確性。
- **`render/`、`ui/`**：瀏覽器實機走查（截圖比對）為主。
- 每期交付前執行：TypeScript 型別檢查 + lint + 單測 + 瀏覽器 QA。

## 7. 技術棧與資料持久化

- **TypeScript + Vite + Three.js + Vitest**；無其他 runtime 依賴。
- 純前端、無伺服器。
- 玩家設定與當前世界種子存 **localStorage**；玩家改動過的區塊存 **IndexedDB**。

## 8. 錯誤處理與邊界情況彙總

| 情況 | 處理 |
|---|---|
| Worker 失敗 | 自動重建 + 主執行緒降級生成 |
| WebGL 不可用 | 顯示相容性錯誤頁面 |
| 區塊生成超時 | 重試 1 次 → 虛空區塊 |
| 玩家掉出世界 | 重生於出生點（生存期接死亡畫面） |
| 背包堆疊滿 | 拒絕拾取/給予，UI 提示 |
| 指標鎖定被瀏覽器拒絕 | 顯示「點擊進入遊戲」提示層 |
