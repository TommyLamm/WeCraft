# WeCraft
### wecraft

> 瀏覽器裡的體素沙盒遊戲（Minecraft 類）—— TypeScript + Three.js，純前端、零後端。
> 創造／生存雙模式、日夜循環、逐格光照與火把、怪物與被動生物、合成、熔爐冶煉、
> IndexedDB 存檔＋雲端輕量進度。

# Synopsis

```bash
npm install
npm run dev        # 開啟 http://localhost:5173
```

標題畫面 →「單人遊戲」→ 點擊畫面鎖定指標 → 開挖。生存模式下天黑小心怪物。

# Description

一個用 TypeScript 撰寫、Three.js 渲染的體素（voxel）遊戲。世界由 16×16 區塊組成，
方塊經貪婪網格化（greedy meshing）+ texture array 合批繪製；四期開發與後續的穩定化／
操控手感／世界生成／被動生物／方塊物品背包／逐格光照與火把批次皆已完成
（目前為 0.9.0，細節見〈專案狀態〉）。

## 遊戲特色

  逐頂點 AO、霧色隨生物群系／時間變化
- 0.6.0（B3）：**多層噪音地形**——海陸（continentalness）／侵蝕（erosion）／山脊
  （peaks & valleys）三層噪音決定地表高度（海平面 62），另有一層氣候場
  （溫度／濕度）決定生物群系
- 0.6.0（B3）：**8 種生物群系**——平原／森林／白樺林／針葉林／雪原／沙漠／山地／
  海洋（含沙灘過渡帶）；地表材質、F3 的 `Biome:` 與霧色同步（id 對照見
  〈與原版的差異〉）
- 0.6.0（B3）：**3 種樹木**（橡木／雲杉／白樺）與**地表裝飾**（蒲公英／罌粟／
  草叢／仙人掌／冰）；新木種與植被都有物品形式（可放進熱鍵欄、創造清單可取）
- 0.7.0（B4）：**被動生物**——雞／豬／羊／牛白天生成在草地／泥土上（離玩家 24 格外、

  火把會照亮周圍（渲染以頂點亮度＋角落平均平滑；光照不入存檔，載入時重新計算）

**創造模式**

  （原版 1.18 起即為 8°）、飢餓 **≤ 6**、攻擊命中。飢餓門檻依原版：**> 6 才能開始**、

  豬 10 血 0.9／羊 8 血 1.3／牛 10 血 1.4），速度保留原版比例（牛 1.5／羊 1.7／
  雞豬 1.9 格/秒）；會漫遊、會跳上 1 格台階、被打會受驚逃跑 5 秒；
  **不主動攻擊、不會自然消失、跨存檔保留**（存檔記種類／座標／血量／朝向）
- **掉落（0.7.0）**：雞 → 生雞肉 1 ＋ 羽毛 0–2；豬 → 生豬肉 1–3；羊 → 生羊肉 1–2 ＋

**雲端進度（Playroom，輕量）**
- 同步內容＝種子、玩家位置與視角、血量／飢餓、遊戲時間、背包物品、
  兩模式的背包（附加欄位，舊版可讀）、進度、個人設定、世界生成版本（附加欄位，
  舊版可讀）、**被動生物（附加欄位 `passiveMobs`，舊版可讀）**；
  體素世界的方塊改動仍只存本機 IndexedDB（不上傳）
- 訪客可玩：未登入照常遊戲＋本機存檔，只是不上傳雲端
- 正式世界載入即讀檔、每 60 秒檢查點＋Save & Quit 時上傳；管理預覽
  （moderation preview）下讀寫皆走隔離槽、重開清除，不碰正式帳號
- 衝突處理：revision 分叉時第二次上傳報 `SAVE_REVISION_CONFLICT`，
  遊戲重讀雲端並套用（toast「雲端有新進度，已同步」），暫停選單顯示
  「有新進度」行＋重試；單槽 64 KiB 上限，超限只 toast
  「雲端空間不足，僅本機存檔」，遊戲不受影響
- 雲端格式版本 **2**（可讀 **1 與 2**）；36 格背包語義改變了 `inventory` 的意義，
  因此 0.8.0 一次升版——format 1 的舊進度**讀入時自動遷移**成 36 格（舊物品留在
  熱鍵列、其餘 27 格留空），下一次檢查點即以 format 2 寫回；讀到無法解讀的資料或
  **集合外**的格式即停用雲端寫入、本機照常（不覆寫既有雲端存檔、不當機）。
  **回退限制：0.8.0 寫出的 format 2 資料，0.7.0（只宣告可讀 format 1）讀不到 →
  平台會擋下不相容的回退**
- 開機即讀雲端進度：讀到可用的雲端存檔時，「繼續遊戲」直接進入該雲端進度
  （開機已套用）；本機與雲端皆有存檔時以雲端為準（合併不做），本機存檔
  於下次儲存時被取代

## 與原版的差異

以下簡化為刻意保留（除註明者外短期不補齊）：

- 世界高度 256（不做 −64..320 擴張）
- 無盔甲
- 無弓（**仍沒有弓**；但箭矢已有取得途徑——骷髏會掉 0–2 支箭，只能當彈藥，無法射出）
- 無床與重生點設定
- 無天氣
- 水是靜態方塊
- 無紅石／附魔／村莊
- 日長預設 600 秒
- 死亡保留物品（不噴裝）
- 生物上限低於原版（B9 後複評）
- 敵對實體不跨存檔；**被動生物自 0.7.0（B4）起跨存檔保留**
- 工具無修補（無鐵砧，B7 明示）

**0.5.0（B2 操控手感）新增的簡化**

- **疾跑入口**：以**雙擊 W** 為主、**按住 Ctrl** 為輔。`Ctrl+W` 是瀏覽器保留鍵
  （可能直接關閉分頁），故不作為主要入口
- **疾跑飢餓門檻**：依原版 —— 飢餓 **> 6** 才能開始、**≤ 6** 立即取消、回到 **≥ 7**
  可再次開始（不設「> 7」的額外鎖定）；創造模式無飢餓條 → 不受此門檻限制
- **雙擊 W 的判定視窗固定 0.35 秒**（7 tick）——原版可在選項裡調整
- **水中與創造模式飛行中不可疾跑**（原版允許：游泳時可疾跑、飛行中按住疾跑鍵可加速）
  ——本批**刻意簡化**
- **疾跑 FOV 固定 +10%**（基準 70° → 77°）——原版為動態計算，本作是簡化值
- **放置連放固定 0.2 秒（4 tick）一次**，且**只重複「放置方塊」**、不重複
  「使用」（不會反覆開工作台／熔爐或進食）
- **潛行防摔邊以「腳下正下方一格」判定支撐**（原版以整個 hitbox 是否仍被支撐判定，
  可探出邊緣約半個身位）；本作**不做** step_height 0.6 的高度差判斷，也**不做**
  「離地 0.6 格內仍受保護」；腳下是水時會被擋在岸邊（潛行時進不了水），
  **世界邊緣尚未載入的區塊暫時視為空氣** → 那一帶的潛行防摔邊可能**短暫生效**
  （被擋住），直到區塊載入
- **F5 三態視角**（第一人稱 → 面後 → 面前 → 第一人稱）：面前視角相機 yaw 為
  玩家 yaw + π，但 **pitch 不鏡像**（不把「看上」翻成「看下」）——只涵蓋 yaw 與相機位置
- **互動射線以相機姿態為準**（相機位置＋相機的 yaw／pitch）；第三身時 reach 補回
  相機↔玩家的 **4 格**（相機實際位移含 0.5 格高度差，實距約 4.031 格）→ 第三身的
  等效可互動距離比第一人稱短約 0.03 格
- **第三身相機不被地形夾住**（固定在玩家前後 4 格，不會被推近）→ 玩家背靠土坡／
  面前有牆時相機可能在牆內；互動已加護欄（跳過相機所在的那一格），完整夾牆留待後續
- **玩家模型無動畫**（無行走循環；只有面後／面前視角才顯示方塊人）
- **Q 丟棄的規則**：Q 丟 1 個、Ctrl+Q 丟整疊、長按每 0.2 秒連丟；**玩家丟出的物品
  2 秒（40 tick）內不可拾**（方塊破壞掉落仍是 0.5 秒／10 tick）；**創造模式 Q 不作用**
  （不丟、不消耗）
- **Q 拋出距離為簡化值**：受本作掉落物的水平阻力影響，落在腳前約 1.5 格內；
  原版約 2–3 格

**0.6.0（B3 世界生成）新增的簡化**

- **生物群系只有 8 種**（原版 Overworld 有 60+ 種）：只做**地表生態**，**沒有河流**、
  **沒有洞穴生態**（原版 6 個地形參數中的 depth 本作**不做**）、**沒有水下地形細節**
- **出生點附近的生態有限**：出生點只會落在**平原／橡木林／山地**（實測 300 個種子：
  125／148／27）→ **世界不會在出生點就給你雪原／沙漠**；雪原／沙漠／針葉林／白樺林
  需走 24–110 格才看得到（玩家可從任何位置出發探索其他生態）
- **地表裝飾只有五種**：蒲公英／罌粟／草叢／仙人掌／冰；本批**沒有種子**、
  **沒有骨粉催熟**
- **掉落規則是簡化版**：花與草**掉自身**（原版需剪刀／骨粉 → 這是**刻意偏離**，
  讓地表裝飾可以再生）；**雲杉／白樺葉不掉落**（與橡木葉一致）、**冰不掉落**
  （原版需絲絨觸碰，本作無絲絨）
- **冰只結在「雪原氣溫」的水面**（氣溫低於雪原門檻、且水深 ≥ 2 格）：沒有原版的
  凍河／凍洋與 snowfall height 機制
- **樹木只有橡木／雲杉／白樺三種**，且**樹距只在「同生態內」強制**（同生態內兩棵樹
  的 Chebyshev 距離 ≥ 3；**跨生態邊界不保**）——原版沒有樹距限制
- **cross 型植被佔滿整格**（兩片對角平面貫通整格、整格高）：原版是**內縮**的
  （約 0.9 格高、短草約 0.8）→ 視覺上比原版略「滿」，貼牆角時會插進鄰格一點
- **仙人掌接觸傷害是「整格判定」**：只有身體框與仙人掌格重疊才受傷，
  **站在仙人掌旁的格子不會受傷**（原版是貼框擦邊判定，碰撞形狀內縮 1/16）
- **舊存檔不保地形一致**：本作**從不保存區塊**，載入時是「從種子重新生成整個世界」
  再套用玩家改動的 overlay → 換生成器等於整片地形改觀（建築可能浮空、埋入或入水）。
  首次載入舊存檔會跳一次「地形已改變」的提示（右上角 toast）
- **生物群系 id 對照**（F3 的 `Biome:` 顯示英文 id，不另建中文對照表）：

  | id | 中文名 | id | 中文名 |
  |---|---|---|---|
  | `ocean` | 海洋（含沙灘過渡帶） | `taiga` | 針葉林 |
  | `plains` | 平原 | `snowy_plains` | 雪原 |
  | `forest` | 森林（橡木） | `desert` | 沙漠 |
  | `birch_forest` | 白樺林 | `mountains` | 山地 |

光照／火把已於 0.9.0（B6）完成；容器、耐久、苦力怕蜘蛛仍排入後續批次（B7–B9），
非永久簡化；完成前暫仍存在。

**0.7.0（B4 被動生物與生物對齊）新增的簡化**

- **生物生成的亮度判準**：B4 以「白天／夜晚」近似（`clockLight(t)`）——**0.9.0 起已改為
  真的逐格光照判準**（敵對：內部天空光 ≤ 7 且方塊光 0；被動：亮度 ≥ 9，見 0.9.0 段），
  `clockLight` 已全檔刪除
- **怪物移動速度低於原版，但比例對齊**：本作殭屍 **3.2** 格/秒（原版約 4.6）、
  骷髏 **3.5**（原版約 5.0）→ 比例 0.25 / 0.23 與原版一致
- **被動生物移動速度同樣低於原版**：牛 **1.5**／羊 **1.7**／雞豬 **1.9** 格/秒
  （原版屬性值 0.2／0.23／0.25，比例對齊、絕對值套用本作的慢速尺度）
- **白天燃燒的遮蔽判定簡化**：只要**頭頂正上方一格是實心方塊（含樹冠葉片）就不燃**，
  不判斷天空光強度、不判天氣、不判頭盔
- **白天燃燒沒有火焰視覺／音效**：生物會燒死，但畫面上沒有火焰特效、也沒有著火音效；
  `SUN_BURN_SEC = 8` 只是「正在燃燒」的**旗標常數**（真正的死亡時間由
  1 HP/s × 20 HP ≈ 20 秒決定，不是「著火 8 秒」）
- **燃料以「可覆蓋冶煉次數」計（小數）**，非原版的連續燃燒計時器 → 1.5 的燃料
  （1 根原木／1 塊木板）會覆蓋 **2 次**冶煉（原版只熔得完 1 件、第 2 件暫停等新燃料），
  每次冶煉向上取整；**1 根木棍（0.5）在原版熔不完任何一件**，在本作卻能熔 1 件
- **生肉熟食掉落只在生物燃燒死亡時發生**——本作沒有生物著火，故**一律掉生肉**
- **腐肉 80%／生雞肉 30% 的「飢餓」狀態效果未實作**（本作沒有狀態效果系統，
  只給食物值：腐肉 4／0.8、生雞肉 2／1.2）
- **飽食度上限＝`maxHunger`(20)**，不是原版的「當前 food level」上限 → 飢餓 19 時
  吃東西，飽食度仍會被補到 20
- **進食的互動與原版一致**（按住右鍵 1.6 秒＝32 tick、滿飢餓不可進食），但
  **進度條只是畫面下方一條橫條**（原版會把食物模型舉起、沒有咀嚼動畫），
  **進食音效沿用放置的軟 thud**（沒有專屬的咀嚼音）
- **羊毛方塊不自然生成**（與原版一致）；創造模式調色盤仍只列方塊
  （完整物品清單屬 B5）
- **被動生物音效未實作**（B4.5 的加分項，本批裁決跳過）：雞／豬／羊／牛**沒有
  叫聲、受傷聲與死亡聲**

被動生物（生成與行為）：

- **選種等機率**（四種各 1/4），原版依**生態**加權（牛大量出現在草原等）→
  B3 的 8 個生態落地後可再調權重
- **生成不檢查水**（生成上下文沒有水位查詢）→ 只有玩家自己在水裡放草／泥土才可能
  生在水裡
- **頭頂空間依 `Math.ceil(height)` 推導**（雞／豬 1 格、羊／牛 2 格），原版一律
  「至少 2 格空間」（雞只有 0.7 高，不需要 2 格）
- **生成距離的上限自訂**：母點 **28–48 格**（成員實際距離 25.2–50.8），原版由模擬
  距離決定（24–128）；spec 只給下限「離玩家 ≥ 24」
- **全場上限 12**（原版沒有硬上限）：場上的總數**永不超過 12**，但**總數達 12 時
  可能只補部分群（1–2 隻）**
- **不會自然消失**（與原版一致：被動生物本來就不 despawn）→ 離很遠也還在場上
- **沒有繁殖／剪毛／擠奶**：動物**不能用餵食繁殖**，數量只能**靠白天自然生成**增加
  （全場上限 12）；本作沒有剪刀 → 羊毛只在羊**死亡**時掉 **1 顆**（掉落量本身與
  原版一致；原版還能剪活羊取得）、沒有水桶 → 牛**不產奶**、**沒有奶桶物品**
- **不會主動攻擊**（沒有攻擊行為、不造成傷害）；被打會受驚逃跑 **5 秒**
  （1.4 倍速、背離攻擊者）—— panic 時長 5 秒是本批自訂值
- **沒有摔傷機制**（本作的摔傷只作用在玩家）→ 動物從高處掉下來不會受傷
- **水中是「漂浮」而非游泳**：不下沉、水平移動照常（沒有推進力、沒有窒息）
- **擊退沿用敵對生物的 `KNOCKBACK_SPEED = 6`**，未依體型縮放（原版依生物大小不同）
- **漫遊換向 2–4 秒一次**（原版的 wandering 是更細的隨機行為）
- **模型是方塊化的簡化版**（方塊身 ＋ 頭 ＋ 兩條腿 ＋ 各種配件），不是原版的多部件
  細緻模型：雞沒有翅膀與尾羽、豬沒有捲尾、牛沒有分趾蹄與乳房、羊沒有分層羊毛；
  **只有兩條腿**（原版四足是四條）；純色 Lambert 材質、沒有貼圖；頭只有一個方塊
  （只有豬鼻與雞喙兩個臉部配件）、只有牛有角；**沒有頭部搖晃／翅膀拍動／尾巴擺動／
  吃東西等動畫**（只有腿的行走擺動）
- **渲染體積刻意小於命中盒**（yaw = 0 時寬 66–82%、深 80–92%）→ 命中盒多出來的邊緣是
  「**打得到卻看不到**」的；yaw ≠ 0 時模型最多超出命中盒 **0.07 格**（旋轉後的外接
  半徑，幾何必然，幾乎不會感覺得到）
- **受擊閃白是整隻動物一起變白 0.1 秒**——**原版沒有這個效果**（沿用本作敵對生物的
  同一個做法）

敵對生物對齊：

- **追擊範圍改為 35 格**（原版 `follow_range`；本作先前是 16 格，**小於最近生成距離
  24** → 新生成的生物永遠不來找玩家）；放棄追擊的 40 格是本作的設計值（原版沒有
  「放棄距離」概念），35–40 之間保留**遲滯帶**避免每幀跳動；原版 `follow_range` 的
  **±5% 隨機加成未實作**（本作是固定的 35 格）
- **骷髏的射箭範圍獨立為 15 格**（原版值）——原版是**兩個獨立的量**（骨骸會追著玩家
  走，但只有靠近到 15 格內才開弓）；本作先前把射箭條件綁在追擊範圍上 → 追擊範圍調成
  35 之後會變成「**從 35 格外射箭**」。**量綱說明**：原版的 15 格是三維球距，本作以
  **水平（XZ）距離**近似
- **原版「離開射程後弓箭上膛等待、回到射程立刻射」未實作**：本作離開射程只是不射箭，
  cooldown 照常走完
- **修正屋簷遮蔽差一格**：原本只檢查生物自己的頭格 → 屋簷下的殭屍會被誤判為曬死；
  現已改成查「**頭頂正上方那一格**」
- **骷髏的移動速度改為略快於殭屍**（3.5 vs 3.2 格/秒，比例對齊原版 0.25 / 0.23）

存檔（被動生物）：

- 只存「**種類／座標／血量／朝向**」：`width`／`height` 由種類推導（不存）；
  **速度與擊退不存**（`vel`／`kbVel` 是暫態）→ 讀檔後的生物是「站著、零速度」重新
  開始漫遊；漫遊方向與受驚狀態也不存（讀檔後不會「還在逃跑」）；id 讀檔後重新指派
- **數量上限 12**（與生成共用同一個常數）：存檔超過 12 筆只留**前 12 筆**
- **單筆壞的紀錄只丟那一筆**（不整包拒絕）→ 存檔不會因為一隻壞掉的羊而變成「無存檔」

**0.8.0（B5 方塊、物品與背包）新增的簡化**

- **背包是 27＋9 的簡化版**：沒有滑鼠拖曳的多格搬運（以**點擊選取→點擊放置**代替）；
  工作台 3×3 的來源列預設只顯示熱鍵列 9 格（工作台面板可看到全部 36 格）；
  創造模式的物品清單是全物品的平鋪清單（**沒有分類頁籤與搜尋**）
- **礦脈是逐格密度模型**（原版是成團的礦脈 blob）；**煤炭沿用均勻密度**（原版是
  近地表的三角帶、且 Y=0 以下無煤）——重排煤炭會讓低窪地形完全沒有燃料，故刻意保留
- **花與草在原版不掉落**（需要剪刀／絲綢觸碰）；本作讓它們掉落自身以便重新種回
  （自 0.6.0 起的既有決策，0.8.0 把掉落接上）
- **冰需要絲綢觸碰才掉落**（本作沒有絲綢觸碰）→ 冰只有創造模式拿得到
- **金／鑽石沒有方塊形式**（9 個金錠合成金塊、9 顆鑽石合成鑽石塊尚未實作）
- **工具無耐久與修補**（B7 處理耐久；本批的金／鑽工具也是滿堆疊＝1、不會壞）
- **讀檔後動物可能短暫懸空**（與玩家同樣的既有行為：區塊還沒生成完成時腳下沒有地面；
  區塊載入、生物活躍後會自行落地）
- **跨地形版本更新（0.7.x → 0.8.0）不還原舊動物**：`WORLDGEN_VERSION` 改變 →
  地形整片改觀、舊座標不可信（可能埋進方塊裡動不了）→ 舊存檔的 `passiveMobs`
  **不套用到場上**（資料仍在存檔檔案裡）；動物之後白天會自然重生（全場上限 12）
- **0.9.0 起光照不入存檔**：光照是導出資料，**載入時重新計算**（存檔 payload 維持 v4、
  雲端維持 format 2）→ 舊存檔載入後的外觀會立刻套用新的光照（洞穴變暗是預期行為，
  不是資料損毀）；火把隨改動方塊的 overlay 保存。**回退限制：0.8.0 不認識
  block id 32（火把）**，用 0.8.0 讀 0.9.0 的存檔時火把會被顯示成空氣
  （`getBlockDef` 對未知 id 落到空氣，**不會崩**；回到 0.9.0 火把會重新出現）

**0.9.0（B6 逐格光照與火把）新增的簡化**

- **天空光的等級不隨時間變**（與原版一致），夜晚的暗來自既有的日照／環境光；本作
  另疊一層輕微的天空比例（**夜間 0.85**），因此**夜晚比原版略暗**。同條併記：原版的
  天空比例是每 8 tick 一階的查表，本作用 `dayFactor(t)` **連續插值**
- **洞穴沒有火把時幾乎全黑**（本作亮度下限 5%，與原版相同）；本作沒有火把時
  會很暗，屬刻意對齊
- **火把的依附方向由世界推導**（下方是實心方塊就立在地上，否則依固定優先序
  +x → −x → +z → −z 貼到某一面牆）；**原版可以自由指定牆面方向**，且火把有
  獨立的 block state——本作一格 1 byte 沒有 state 空間，存檔往返不會掉方向
- **過濾方塊（水、葉、冰）不會衰減天空光**（原版每格 −1）——本作所有透明方塊
  一律不過濾
- **生物與掉落物不使用逐格光照**（仍由場景燈光照亮）→ 黑暗的洞穴裡敵對生物
  仍看得到
- **生怪判準已升級為光照判準**（對齊原版）：敵對生物需要**內部天空光 ≤ 7 且
  方塊光 = 0**（正午地表不再出怪、夜間地表與洞穴會出）；被動生物需要**亮度 ≥ 9**
  （地表夜間也算，與原版一致）
- **被動生物的光照判準比原版寬**：本作只要 `max(天空光, 方塊光) ≥ 9` 就能生成；
  原版在「天空光未滿 15（半遮蔽）」的位置還要求方塊光 ≥ 9 → 本作會在原版不會
  生成的位置生成被動生物
- **火把不能放進水中、也不能取代植被**（只能放進空氣格）；原版可以把火把
  放進水裡取代草

```
└── main.ts   組合根（composition root）
```

架構紅線（review + grep 強制）：

- `core/` `world/` `player/` 不得 import Three.js 或碰 DOM（`player/input.ts` 的
  事件監聽為既有例外）
- Three.js 只出現在 `render/` 與 `main.ts`
- `ui/` 不得 import `bus` singleton（由 main 注入）
- Runtime 依賴只有 `three`；其餘皆為 devDependencies
- 測試與來源同置：`src/**/*.test.ts`（jsdom 為全域環境）

# Example

一次典型的生存開局：

```text
1. 標題畫面 →「單人遊戲」（新世界，seed 1337 預設）
2. 砍樹拾原木 → E 背包 2×2 合成木板／木棍／工作台 → 放置工作台 → 右鍵 3×3 做木鎬
3. 帶木鎬挖石頭（掉鵝卵石，「鵝卵石」進度）→ 3×3 做石鎬 → 挖鐵礦（掉生鐵）＋
   煤炭（「鐵礦」進度）
4. 8 顆鵝卵石做熔爐 → 放置 → 右鍵開爐：生鐵＋煤炭 → 10 秒冶煉 → 取出鐵錠
   （「燃燒吧」進度）→ 做鐵鎬（「鐵製工具」進度）
5. 白天在平原找雞豬羊牛群（離你 24 格外）→ 打一隻羊拿生羊肉＋羊毛（「牧場」進度）
   → 熔爐熔成羊排；打橡木樹葉有 0.5% 掉蘋果 → 手持蘋果**按住右鍵 1.6 秒**吃掉
   （「吃個蘋果」進度）
6. 夜晚持劍殺殭屍（白天它會在陽光下燒死，屋簷下不會）→ 撿腐肉
7. Esc → Save & Quit；再次進入 →「繼續遊戲」→ 位置、方塊、血量、時間全數還原
   （熔爐方塊還在；爐內未取出的冶煉進度會重置；**白天遇到的雞豬羊牛也還在**）
8. Esc → Game Mode: Creative → 雙擊 Space 起飛勘察地形；切回生存自動落地
```
