# WeCraft
### wecraft

> 瀏覽器裡的體素沙盒遊戲（Minecraft 類）—— TypeScript + Three.js，純前端、零後端。
> 創造／生存雙模式、日夜循環、怪物、合成、熔爐冶煉、IndexedDB 存檔＋雲端輕量進度。

# Synopsis

```bash
npm install
npm run dev        # 開啟 http://localhost:5173
```

標題畫面 →「單人遊戲」→ 點擊畫面鎖定指標 → 開挖。生存模式下天黑小心怪物。

# Description

一個用 TypeScript 撰寫、Three.js 渲染的體素（voxel）遊戲。世界由 16×16 區塊組成，
方塊經貪婪網格化（greedy meshing）+ texture array 合批繪製；四期開發與後續的穩定化／
操控手感批次皆已完成並通過瀏覽器走查（目前為 0.5.0，細節見〈專案狀態〉）。

## 遊戲特色

**世界**
- 區塊化地形（貪婪網格化 + `sampler2DArray` 紋理陣列，F3 顯示每幀三角數）
- 日 → 暮 → 夜 → 晝循環，天空、霧、光照同步變化
- 半透明水面 + 水下霧效
- 第三期：方塊太陽／月亮＋天空漸層、方形體積雲（可開關、會飄移）、即時陰影（可開關）、
  逐頂點 AO、霧色隨生物群系／時間變化

**創造模式**
- 即時挖掘、熱鍵欄無限方塊、無血量／飢餓
- 雙擊 Space 起飛，Space / Shift 升降

**生存模式**
- 血量／飢餓 HUD（心形 + 雞腿格）
- 疾跑：**雙擊 W** 開始（鎖存，不必再按任何鍵），按住 **Ctrl** 也可疾跑（輔助入口）。
  取消條件：停止前進、潛行（Shift）、在水中、創造模式飛行中、撞到方塊的夾角 **> 8°**
  （原版 1.18 起即為 8°）、飢餓 **≤ 6**、攻擊命中。飢餓門檻依原版：**> 6 才能開始**、
  **≤ 6 立即取消**、回到 **≥ 7** 可再次開始（無額外鎖定）。任何取消條件成立時，
  雙擊 W 的鎖存會一併清除（要再雙擊一次才會重新開始）。疾跑時視野放大 10%
  （基準 70° → 77°）並平滑過渡。創造模式也能疾跑，但沒有飢餓條 → 不受飢餓門檻限制
  （創造模式飛行中仍不可疾跑）
- 挖掘需要時間，依原版公式結算：硬度 ×（可收穫 1.5／不可收穫 5）÷ 工具速度；
  木鎬 2×／石鎬 4×／鐵鎬 6×；石頭與煤礦需木鎬以上、鐵礦需石鎬以上；
  徒手或錯工具挖石類 ×5 且不掉落
- 方塊挖破後掉落地面，走近自動拾取（熱鍵欄即全部背包）
- 夜晚出怪：殭屍近戰追擊、骷髏保持距離射箭；飢餓回血、墜落傷害
- 合成：背包 2×2（木板／木棍／工作台）＋ 放置工作台右鍵 3×3 製作工具，全套共
  13 份配方（木板／木棍／工作台＋木／石／鐵三階鎬斧劍＋熔爐）
- 石頭挖破掉鵝卵石（Minecraft 對應）：石製工具、熔爐配方與「鵝卵石」進度
  由此解鎖（石頭、煤礦需木鎬以上；鐵礦需石鎬以上）
- 熔爐：放置後右鍵開啟，生鐵／沙為冶煉原料（舊存檔的鐵礦物品仍可熔煉）、
  煤炭為燃料（原木、木板、木棍也可當燃料），每件冶煉 10 秒；鐵錠／玻璃
  取出即「燃燒吧」進度，鐵錠可做鐵製工具（鐵鎬挖鐵更快）
- 進食：殭屍近戰擊殺掉 1 顆蘋果（生存限定、必掉；骷髏不掉）→ 手持蘋果
  右鍵（對空或一般方塊）食用，回 4 點飢餓（滿 20 點）＋2.4 飽食度
  （飽時照吃，溢出浪費），解鎖「吃個蘋果」
- 死亡畫面 → 重生：血量飢餓回滿、回到出生點、物品保留（附死因文案：墜落／殭屍／骷髏／飢餓）
- 暫停選單可雙向切換創造／生存（兩模式各自保留背包與狀態；創造第一次進入
  補滿 9×64，之後保留你在創造的配置）
- IndexedDB 存檔（`wecraft-save`；存檔 payload v1／v2 照讀並升級 v3，v3 起另存
  兩模式的背包與生存數值）：改動方塊 + 玩家狀態 → Save & Quit → Continue 全還原；
  熔爐「方塊」隨世界改動保留，但爐內進行中的冶煉不存檔，Continue 後重置
  （爐內有物品時 toast「熔爐進度已重置」）；v1 舊檔 Continue 後進度全鎖（新系統起算）
- 第三期：程序化音效（挖掘／放置／腳步／風聲／鳥叫，音量設定、背景分頁自動靜音）、
  挖掘裂紋＋破壞粒子、第一人稱手持模型（挖掘揮動）、進度系統＋右上 toast 通知
  （第四期再添鐵器／冶煉／進食三進度，累計 12 項）

**雲端進度（Playroom，輕量）**
- 同步內容＝種子、玩家位置與視角、血量／飢餓、遊戲時間、背包物品、
  兩模式的背包（附加欄位，舊版可讀）、進度、個人設定；體素世界的方塊改動
  仍只存本機 IndexedDB（不上傳）
- 訪客可玩：未登入照常遊戲＋本機存檔，只是不上傳雲端
- 正式世界載入即讀檔、每 60 秒檢查點＋Save & Quit 時上傳；管理預覽
  （moderation preview）下讀寫皆走隔離槽、重開清除，不碰正式帳號
- 衝突處理：revision 分叉時第二次上傳報 `SAVE_REVISION_CONFLICT`，
  遊戲重讀雲端並套用（toast「雲端有新進度，已同步」），暫停選單顯示
  「有新進度」行＋重試；單槽 64 KiB 上限，超限只 toast
  「雲端空間不足，僅本機存檔」，遊戲不受影響
- 雲端格式版本 1；讀到無法解讀的資料或格式即停用雲端寫入、本機照常
  （不覆寫既有雲端存檔、不當機）
- 開機即讀雲端進度：讀到可用的雲端存檔時，「繼續遊戲」直接進入該雲端進度
  （開機已套用）；本機與雲端皆有存檔時以雲端為準（合併不做），本機存檔
  於下次儲存時被取代

**介面**
- 熱鍵欄、背包、合成介面、熔爐面板、暫停選單、死亡畫面（皆純 DOM，由 `main.ts`
  注入回呼通訊，不 import bus／Three）
- F3 調試疊層：FPS、XYZ 座標、Block、Chunks、Seed、Triangles、Mode

## 與原版的差異

以下簡化為刻意保留（除註明者外短期不補齊）：

- 世界高度 256（不做 −64..320 擴張）
- 無盔甲
- 無弓（箭矢沒有取得途徑；骷髏射出的箭是彈藥，不會掉落）
- 無床與重生點設定
- 無天氣
- 水是靜態方塊
- 無紅石／附魔／村莊
- 日長預設 600 秒
- 死亡保留物品（不噴裝）
- 生物上限低於原版（B9 後複評）
- 敵對實體不跨存檔（被動生物自 B4 起持久化）
- 工具無修補（無鐵砧，B7 明示）

**0.5.0（B2 操控手感）新增的簡化**

- **疾跑入口**：以**雙擊 W** 為主、**按住 Ctrl** 為輔。`Ctrl+W` 是瀏覽器保留鍵
  （可能直接關閉分頁），故不作為主要入口
- **疾跑飢餓門檻**：依原版 —— 飢餓 **> 6** 才能開始、**≤ 6** 立即取消、回到 **≥ 7**
  可再次開始（不設「> 7」的額外鎖定）；創造模式無飢餓條 → 不受此門檻限制
- **雙擊 W 的判定視窗固定 0.35 秒**（7 tick）——原版可在選項裡調整
- **水中與創造模式飛行中不可疾跑**（原版允許：游泳時可疾跑、飛行中按住疾跑鍵可加速）
  ——本批**刻意簡化**
- **疾跑 FOV 固定 +10%**（基準 70° → 77°）——原版為動態計算，本作是簡化值
- **放置連放固定 0.2 秒（4 tick）一次**，且**只重複「放置方塊」**、不重複
  「使用」（不會反覆開工作台／熔爐或進食）
- **潛行防摔邊以「腳下正下方一格」判定支撐**（原版以整個 hitbox 是否仍被支撐判定，
  可探出邊緣約半個身位）；本作**不做** step_height 0.6 的高度差判斷，也**不做**
  「離地 0.6 格內仍受保護」；腳下是水時會被擋在岸邊（潛行時進不了水），
  **世界邊緣尚未載入的區塊暫時視為空氣** → 那一帶的潛行防摔邊可能**短暫生效**
  （被擋住），直到區塊載入
- **F5 三態視角**（第一人稱 → 面後 → 面前 → 第一人稱）：面前視角相機 yaw 為
  玩家 yaw + π，但 **pitch 不鏡像**（不把「看上」翻成「看下」）——只涵蓋 yaw 與相機位置
- **互動射線以相機姿態為準**（相機位置＋相機的 yaw／pitch）；第三身時 reach 補回
  相機↔玩家的 **4 格**（相機實際位移含 0.5 格高度差，實距約 4.031 格）→ 第三身的
  等效可互動距離比第一人稱短約 0.03 格
- **第三身相機不被地形夾住**（固定在玩家前後 4 格，不會被推近）→ 玩家背靠土坡／
  面前有牆時相機可能在牆內；互動已加護欄（跳過相機所在的那一格），完整夾牆留待後續
- **玩家模型無動畫**（無行走循環；只有面後／面前視角才顯示方塊人）
- **Q 丟棄的規則**：Q 丟 1 個、Ctrl+Q 丟整疊、長按每 0.2 秒連丟；**玩家丟出的物品
  2 秒（40 tick）內不可拾**（方塊破壞掉落仍是 0.5 秒／10 tick）；**創造模式 Q 不作用**
  （不丟、不消耗）
- **Q 拋出距離為簡化值**：受本作掉落物的水平阻力影響，落在腳前約 1.5 格內；
  原版約 2–3 格

光照／火把、容器、耐久、苦力怕蜘蛛已排入 B6–B9，非永久簡化；完成前暫仍存在。

## 操作

| 操作 | 功能 |
|---|---|
| 點擊畫面 | 鎖定指標進入遊戲 |
| 滑鼠 | 視角轉動 |
| W / A / S / D | 移動 |
| 雙擊 W | 疾跑（主入口；鎖存，不必再按任何鍵。停止前進即停） |
| Space | 跳躍 / 飛行上升（創造：雙擊起飛） |
| Shift | 潛行（移速變慢、著地時不會走出邊緣）/ 飛行下降 |
| Ctrl | 疾跑（輔助入口；`Ctrl+W` 是瀏覽器保留鍵，可能被瀏覽器吃掉） |
| 左鍵 | 挖掘（按住連續挖）/ 攻擊 |
| 右鍵 | 放置方塊（**按住可連續放置**，每 0.2 秒一個）/ 右鍵工作台開 3×3 |
| Q | 丟棄選取格 1 個（長按每 0.2 秒連丟） |
| Ctrl+Q | 丟棄選取格整疊 |
| 1–9 / 滾輪 | 熱鍵欄切換 |
| E | 背包（生存模式含 2×2 合成格；創造隱藏合成） |
| Esc | 暫停選單（解鎖指標） |
| F3 | 調試資訊開關 |
| F5 | 切換視角（第一人稱 / 面後 / 面前） |

## 架構

```
src/
├── core/     遊戲狀態與純邏輯：bus、items、inventory、recipes、settings、日夜數學
├── world/    世界與模擬：區塊、貪婪 mesher、raycast、drops、mobs、IndexedDB 存檔
├── player/   玩家：AABB 物理、血量飢餓、挖掘互動、輸入
├── render/   Three.js：場景、光照、區塊網格、紋理陣列（唯一的 3D 層）
├── ui/       純 DOM/CSS：HUD、選單、背包、合成、死亡畫面
└── main.ts   組合根（composition root）
```

架構紅線（review + grep 強制）：

- `core/` `world/` `player/` 不得 import Three.js 或碰 DOM（`player/input.ts` 的
  事件監聽為既有例外）
- Three.js 只出現在 `render/` 與 `main.ts`
- `ui/` 不得 import `bus` singleton（由 main 注入）
- Runtime 依賴只有 `three`；其餘皆為 devDependencies
- 測試與來源同置：`src/**/*.test.ts`（jsdom 為全域環境）

# Example

一次典型的生存開局：

```text
1. 標題畫面 →「單人遊戲」（新世界，seed 1337 預設）
2. 砍樹拾原木 → E 背包 2×2 合成木板／木棍／工作台 → 放置工作台 → 右鍵 3×3 做木鎬
3. 帶木鎬挖石頭（掉鵝卵石，「鵝卵石」進度）→ 3×3 做石鎬 → 挖鐵礦（掉生鐵）＋
   煤炭（「鐵礦」進度）
4. 8 顆鵝卵石做熔爐 → 放置 → 右鍵開爐：生鐵＋煤炭 → 10 秒冶煉 → 取出鐵錠
   （「燃燒吧」進度）→ 做鐵鎬（「鐵製工具」進度）
5. 夜晚持劍殺殭屍 → 拾蘋果 → 手持對空右鍵吃掉（「吃個蘋果」進度）
6. Esc → Save & Quit；再次進入 →「繼續遊戲」→ 位置、方塊、血量、時間全數還原
   （熔爐方塊還在；爐內未取出的冶煉進度會重置）
7. Esc → Game Mode: Creative → 雙擊 Space 起飛勘察地形；切回生存自動落地
```

# Install

從原始碼安裝（`package.json` 標記 `private: true`，未發布至 npm）：

```bash
git clone <repo-url>
cd wecraft
npm install
npm run dev        # 開發伺服器
npm run build      # 類型檢查 + 產出 dist/
npm run preview    # 預覽產出
```

# Test

```bash
npm test           # vitest run — 924 tests / 57 files 全綠
npm run test:watch # watch 模式
npm run typecheck  # tsc --noEmit
npm run lint       # eslint .
```
